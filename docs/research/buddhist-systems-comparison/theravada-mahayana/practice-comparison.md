## 一、结论总纲

上座部与大乘、汉传和藏传之间，最大的修行差异不在于“一个修禅，一个不修禅”，而在于：

1. **以什么为终点**  
    上座部声闻道以阿罗汉果、漏尽、停止再生为完成；大乘以圆满佛果为终点。
    
2. **谁必须走哪条路**  
    上座部允许声闻、独觉、正等正觉三种志向；大乘原则上把菩萨道视为最高乃至唯一究竟道路。
    
3. **修行要经过多长时间**  
    上座部认为阿罗汉果可于现生证得，但正等正觉必须历经极长时期圆满波罗蜜；许多大乘、禅宗和密教系统则容许现生成佛、即身成佛或快速圆满佛道的理论。
    
4. **智慧具体观察什么**  
    上座部主要观察名色、五蕴、十二处、十八界、缘起及其无常、苦、无我；中观观察一切法无自性；唯识观察能取所取、识的虚妄分别；如来藏、禅宗、大手印和大圆满常以直接认识心性为中心。
    
5. **定在道中的地位**  
    上座部内部存在先止后观、止观并修和偏纯观等路线；汉传天台强调止观双运，禅宗强调直接照见，净土以信愿持名为中心，密教则把定与复杂观想、身语意仪轨及微细身修法结合。
    
6. **戒律能否因高阶见地而改变**  
    上座部认为经律始终有效，任何定境、空性见或秘密传承都不能取消根本戒；部分密教修法则以特殊灌顶、三昧耶和密续语境处理某些通常被禁止的象征或行为，这构成最尖锐的实践分歧。
    
7. **觉悟是断烦恼，还是认出本有觉性**  
    上座部以贪、瞋、痴及结使被道智实际断除为判准；某些大乘和藏传体系则更强调显露、认出或安住于本具的智慧，但其正统解释通常仍要求去除障碍，不能简单理解为“认出之后无需修行”。

# 二、上座部修行的经典总结构

## 1. 经藏中的渐次训练

MN 39《马城大经》是上座部渐次训练的重要文本，其修行框架包括：

1. 惭与愧；
    
2. 身行清净；
    
3. 语行清净；
    
4. 意行清净；
    
5. 活命清净；
    
6. 防护诸根；
    
7. 饮食知量；
    
8. 警寤；
    
9. 正念正知；
    
10. 住于僻静处；
    
11. 断除五盖；
    
12. 进入四禅；
    
13. 如实知见；
    
14. 证得漏尽。
    

SuttaCentral 核验显示，该经 UID 为 `mn39`，巴利题名为 _Mahāassapurasutta_，并有汉译和平行资料。它表明早期上座部修道不是孤立地练习一种技术，而是从行为、生活方式、根门防护、正念、禅定，一直推进到解脱智慧的整体训练。

简化为：

> 戒与生活整顿 → 防护和正念 → 远离五盖 → 禅那 → 如实知见 → 漏尽。

## 2. 三学

全部修行可以归为：

- 增上戒学（adhisīla）
    
- 增上心学（adhicitta）
    
- 增上慧学（adhipaññā）
    

三者不是彼此割裂：

- 戒减少追悔与粗重烦恼；
    
- 定令心统一、柔软、明净；
    
- 慧如实观察并断除无明；
    
- 慧又进一步净化戒和定。
    

## 3. 八圣道

八正道可归入三学：

### 慧

- 正见
    
- 正思惟
    

### 戒

- 正语
    
- 正业
    
- 正命
    

### 定

- 正精进
    
- 正念
    
- 正定
    

因此，上座部不会认为“只保持觉知”或“只练专注”就是完整圣道。

# 三、《清净道论》的完整修行次第

《清净道论》把上座部修道组织为：

1. 戒；
    
2. 定；
    
3. 慧。
    

又依《传车经》的传统建立七清净：

1. 戒清净（sīlavisuddhi）
    
2. 心清净（cittavisuddhi）
    
3. 见清净（diṭṭhivisuddhi）
    
4. 度疑清净（kaṅkhāvitaraṇavisuddhi）
    
5. 道非道智见清净（maggāmaggañāṇadassanavisuddhi）
    
6. 行道智见清净（paṭipadāñāṇadassanavisuddhi）
    
7. 智见清净（ñāṇadassanavisuddhi）
    

上传资料《智慧之光》明确以戒清净、心清净、见清净等七清净作为教学骨架，并把近行定和八等至归入心清净。

## 1. 戒清净

包括：

- 比丘、比丘尼、沙弥或在家戒；
    
- 防护诸根；
    
- 活命清净；
    
- 对衣食住药的如理省察；
    
- 犯轻罪后的如法忏悔和恢复清净。
    

《南传菩萨道》也区分清净戒、不清净戒、执取戒和不执取戒，并说明正在禅修者必须先恢复戒的清净。

戒在这里不只是道德规范，也有直接禅修功能：

- 减少追悔；
    
- 减少感官刺激；
    
- 令心容易安住；
    
- 防止以邪命和伤害行为破坏定慧。
    

## 2. 心清净

《清净道论》列出四十业处：

### 十遍

- 地
    
- 水
    
- 火
    
- 风
    
- 青
    
- 黄
    
- 赤
    
- 白
    
- 光明
    
- 限定虚空
    

### 十不净

观察尸体不同腐坏阶段。

### 十随念

- 佛
    
- 法
    
- 僧
    
- 戒
    
- 施
    
- 天
    
- 死
    
- 身至念
    
- 入出息念
    
- 寂止随念
    

### 四梵住

- 慈
    
- 悲
    
- 喜
    
- 舍
    

### 四无色处

- 空无边处
    
- 识无边处
    
- 无所有处
    
- 非想非非想处
    

### 其他两种

- 食厌想
    
- 四界分别观
    

这些业处不是全部达到同一种定：

- 有些达到近行定；
    
- 有些达到初禅；
    
- 有些可至第四禅；
    
- 无色业处可进入四无色定。
    

## 3. 禅那路线

典型次第为：

1. 选定业处；
    
2. 调整住处、饮食、生活；
    
3. 学习取相；
    
4. 遍作相；
    
5. 取相；
    
6. 似相；
    
7. 近行定；
    
8. 安止定；
    
9. 初禅；
    
10. 熟练五自在；
    
11. 检查初禅粗劣处；
    
12. 进入第二、第三、第四禅；
    
13. 必要时进入无色定。
    

《清净道论》说明，行者从熟练的较低禅出定，观察其粗重和缺点，再倾向更寂静的高一级禅；每一级都需熟练后再前进。

## 4. 四界分别与名色辨识

另一典型路线是：

1. 观察地、水、火、风四界性质；
    
2. 破除“整体身体”的密集想；
    
3. 辨识色聚和色法；
    
4. 辨识心与心所；
    
5. 区分名与色；
    
6. 进入见清净。
    

《智慧之光》依《清净道论》说明，四界分别观可达到近行性质的定，然后以此辨识自性法。

## 5. 见清净

见清净的核心是：

> 只有名与色的因缘过程，没有一个在其中支配、拥有或恒常存在的人。

这并非只在思想上接受“无我”，而是辨识：

- 什么是色；
    
- 什么是受、想、思、触、识等名法；
    
- 它们如何依条件现起；
    
- 身心经验如何由诸法组成。
    

## 6. 度疑清净

行者观察名色的过去、现在、未来因缘，尤其是：

- 无明
    
- 爱
    
- 取
    
- 业
    
- 食
    
- 心
    
- 温度
    
- 业生色等
    

由此断除疑惑：

- 我从哪里来？
    
- 谁投生？
    
- 有没有一个灵魂迁移？
    
- 身心是否无因而生？
    
- 是神、自我或偶然创造身心吗？
    

## 7. 道非道智见清净

行者开始观察诸行的：

- 生起
    
- 消灭
    
- 无常
    
- 苦
    
- 无我
    

此时可能出现：

- 光明
    
- 强烈喜悦
    
- 轻安
    
- 信
    
- 精进
    
- 乐
    
- 快速智慧
    
- 强念
    
- 平等舍
    
- 对这些经验的微细执著
    

《清净道论》把它们称为观的染污。行者必须辨认：

> 光明、喜悦、轻安和特殊体验不是圣道，也不是涅槃。

这一点与许多传统中把光、明觉、空寂或强烈乐受迅速认作究竟觉悟的风险，形成重要对照。

## 8. 行道智见清净

《清净道论》第二十一品列出观智进程：

1. 生灭智
    
2. 坏灭智
    
3. 怖畏智
    
4. 过患智
    
5. 厌离智
    
6. 欲解脱智
    
7. 审察智
    
8. 行舍智
    
9. 随顺智
    

正文说明，无常由于连续相而被遮蔽，苦由于姿势变换而被遮蔽，无我由于密集整体感而被遮蔽；当行者看见生灭、持续压迫和诸界分解时，三相才清楚显现。

到坏灭智时，注意力主要转向诸行的破坏、消失和灭去；继而现见诸行无可靠核心，产生厌离、欲求解脱和对诸行的平等舍。

## 9. 智见清净

最后发生：

1. 种姓智或前导转换；
    
2. 道智；
    
3. 果智；
    
4. 省察智。
    

四道分别断除结使：

### 入流道

断：

- 身见
    
- 疑
    
- 戒禁取
    

### 一来道

削弱欲贪与瞋。

### 不还道

断：

- 欲贪
    
- 瞋
    

### 阿罗汉道

断：

- 色贪
    
- 无色贪
    
- 慢
    
- 掉举
    
- 无明
    

完成后不再有更高世间或出世修行任务需要完成。

# 四、上座部内部并非只有一种技术路线

## 1. 先止后观

次第：

1. 戒清净；
    
2. 修安般念、遍处、慈心等；
    
3. 达近行或禅那；
    
4. 从定出；
    
5. 观察禅支、心所、色身和缘起；
    
6. 观三相；
    
7. 观智成熟；
    
8. 道果。
    

帕奥体系是现代最典型的系统化先止后观路线：

- 安般念或四界分别观；
    
- 四禅、无色定；
    
- 三十二身分；
    
- 白骨观；
    
- 十遍；
    
- 四护卫禅；
    
- 色业处；
    
- 名业处；
    
- 缘起；
    
- 观智；
    
- 道果。
    

## 2. 纯观或干观路线

大致次第：

1. 戒；
    
2. 直接观察身体、感受、心和法；
    
3. 培养刹那定；
    
4. 辨识名色；
    
5. 观察生灭；
    
6. 观智进展；
    
7. 道果。
    

“纯观”不等于完全没有定。上传资料说明，即使纯观行者也必须具备足以如实观察的刹那定；没有相应定力，不能生起解脱门。

## 3. 定慧交替

泰国森林传统常采用：

- 佛随念；
    
- 呼吸；
    
- 身体观察；
    
- 死随念；
    
- 行禅；
    
- 痛受观察；
    
- 以智慧处理散乱；
    
- 心疲劳时返回定；
    
- 心有力量后继续分析身体、感受和心。
    

阿姜摩诃布瓦说明：

- 欲求寂静时修止；
    
- 欲求真实知见时运用智慧；
    
- 两者可在不同时段交替；
    
- 不应混乱到既不能安止也不能分析。
    

《Forest Dhamma》则进一步提出两种可能：

- 定生慧；
    
- 慧令定生起。
    

并区分刹那定、近行定和安止定。

## 4. 念住贯穿路线

部分森林传统不严格按技术课程推进，而把重点放在：

- 每一姿势保持正念；
    
- 观察烦恼当下活动；
    
- 身体、感受和心成为直接战场；
    
- 定力足够时以智慧切入；
    
- 对最微细“能知者”也不执著。
    

《帕蒂帕达》强调，四念处与四圣谛就是修行战场，道果不在身心经验以外。

美琪乔的传记还特别描述：她一度把极清明、集中、似乎恒常的“能知核心”误认作涅槃，最后通过持续观察其细微波动，破除对此光明心的执著。

这说明正统上座部森林修行并不以找到一个永恒“觉知核心”为终点。

# 五、上座部声闻道与菩萨道必须分开

## 1. 声闻道

修行目标：

> 听闻佛法，依戒定慧证四道四果，最终成为阿罗汉。

可以在现生完成。

## 2. 上座部菩萨道

修行次第并不是直接修十地，而是：

1. 在佛前发成佛愿；
    
2. 具足接受确定授记的条件；
    
3. 获佛授记；
    
4. 长期修十波罗蜜；
    
5. 修三层波罗蜜：
    
    - 普通波罗蜜
        
    - 增上波罗蜜
        
    - 究竟波罗蜜
        
6. 圆满五大舍；
    
7. 最后一生出生、出家、苦行；
    
8. 菩提树下独自发现四圣谛；
    
9. 成正等正觉。
    

十波罗蜜为：

- 布施
    
- 持戒
    
- 出离
    
- 智慧
    
- 精进
    
- 忍辱
    
- 真实
    
- 决意
    
- 慈
    
- 舍
    

上座部菩萨成佛的最短传统时限为四阿僧祇与十万大劫，不接受只修数日、数年或一生便圆满正等正觉。

## 3. 菩萨在成佛前是否证阿罗汉果

传统答案是否定的。

因为一旦证得阿罗汉果：

- 再生因已断；
    
- 不再继续轮回圆满佛波罗蜜；
    
- 不会后来转成正等正觉佛。
    

所以，上座部菩萨虽然修定、神通、慈悲和观慧，但不会在授记后的历程中提前证取声闻阿罗汉果。

# 六、早期印度大乘菩萨道

早期大乘不是单一标准课程，但大体有以下结构。

## 1. 发菩提心

核心愿望是：

> 为利益一切众生而成就无上正等菩提。

分为：

- 愿菩提心；
    
- 行菩提心。
    

它与上座部菩萨愿有相似之处，但重大差异在于：

- 大乘普遍鼓励所有修行者发心；
    
- 上座部把成佛愿视为少数人的特殊志向。
    

## 2. 六波罗蜜

- 布施
    
- 持戒
    
- 忍辱
    
- 精进
    
- 禅定
    
- 般若
    

后扩展为十波罗蜜：

- 方便
    
- 愿
    
- 力
    
- 智
    

## 3. 四摄法

- 布施
    
- 爱语
    
- 利行
    
- 同事
    

修行不只处理个人烦恼，也把建立摄受众生的能力视为道的一部分。

## 4. 无住涅槃倾向

菩萨不以尽快进入个人涅槃为最终目标，而以：

- 不住轮回；
    
- 不住寂灭；
    
- 依悲愿持续利益众生
    

为理想。

上座部会接受佛和大菩萨长期利他，却不接受阿罗汉的般涅槃属于应避免的“偏空寂灭”。

---

# 七、十地菩萨次第

成熟大乘通常建立十地：

1. 欢喜地
    
2. 离垢地
    
3. 发光地
    
4. 焰慧地
    
5. 难胜地
    
6. 现前地
    
7. 远行地
    
8. 不动地
    
9. 善慧地
    
10. 法云地
    

再进入：

- 等觉；
    
- 妙觉或佛地。
    

## 与上座部四道四果的关系

不能简单对应：

|上座部|大乘|
|---|---|
|入流|不能直接等同初地|
|一来|不能等同某一菩萨地|
|不还|不能等同高地菩萨|
|阿罗汉|大乘常视为低于佛地|
|正等正觉|大乘佛地|

根本原因是两套系统对“断了什么障碍”定义不同。

大乘常区分：

- 烦恼障；
    
- 所知障。
    

一般认为阿罗汉断烦恼障，但未圆满断所知障；上座部不接受一个已漏尽的阿罗汉还必须再走十地以完成解脱。

# 八、般若与中观的修行路线

## 1. 基础

中观修行通常不只是思辨，而包括：

1. 依止善知识；
    
2. 持戒；
    
3. 出离；
    
4. 慈悲；
    
5. 菩提心；
    
6. 奢摩他；
    
7. 观察诸法无自性；
    
8. 止观双运；
    
9. 积集福德与智慧资粮；
    
10. 十地佛果。
    

## 2. 中观分析方法

常见观察包括：

- 果从自身生、他生、共生还是无因生？
    
- 一个事物与其部分是一还是异？
    
- 人与五蕴是一、是异、拥有五蕴还是依于五蕴？
    
- 因果、运动、时间和自性是否可以独立成立？
    
- 所有法是否只是依因、依缘、依部分、依名称安立？
    

## 3. 与上座部观禅的共同点

都可以：

- 分析五蕴；
    
- 破除整体的人我；
    
- 观察缘起；
    
- 不把身心当作独立实体；
    
- 断除常见和断见；
    
- 培养离贪。
    

## 4. 实质差异

上座部观禅通常以：

- 真实出现的名色法；
    
- 它们的特相；
    
- 生灭；
    
- 三相；
    
- 条件关系
    

为主要对象。

中观则进一步追问：

> 即使最细微的法，是否具有不依赖其他条件的自性？

因此，中观不仅破人我，也以其特有哲学方式破法自性。

## 5. 上座部的主要保留

上座部不接受：

- 必须通过中观论证才能证涅槃；
    
- 阿毗达摩究竟法只是需要完全取消的实体执；
    
- 空性体验可以代替四圣谛的具体遍知、断除、证悟和修习；
    
- 一切法空意味着业果和戒律仅有任意的约定效力。

# 九、瑜伽行／唯识的修行路线

## 1. 资粮与加行

大乘唯识常依五位：

1. 资粮位
    
2. 加行位
    
3. 通达位
    
4. 修习位
    
5. 究竟位
    

其中加行位又常分：

- 暖
    
- 顶
    
- 忍
    
- 世第一法
    

## 2. 核心观法

- 观察所取境依识显现；
    
- 观察能取心也不可独立成立；
    
- 破除能取、所取二分；
    
- 体悟圆成实性；
    
- 转依；
    
- 转识成智。
    

## 3. 三性观

- 遍计所执性：错误安立的主客体；
    
- 依他起性：依因缘生起的识流；
    
- 圆成实性：依他起中永离能所二取的真实性。
    

## 4. 与上座部的对应

可以功能比较：

|唯识|上座部近似项目|
|---|---|
|观察虚妄分别|观察想、见、心行|
|观察识流|心路过程、名法|
|破能所执|六处、触、受、爱之缘起分析|
|转依|道智断烦恼后心流根本改变|

但不能等同：

- 阿赖耶识不等于有分心；
    
- 转八识成四智不等于四道四果；
    
- 三性不等于无常、苦、无我三相；
    
- 唯识五位不等于七清净。

# 十、如来藏型修行

如来藏体系常见两种方向。

## 1. 除垢显净型

修行逻辑是：

1. 心性本来清净；
    
2. 烦恼属于客尘；
    
3. 修道不是制造佛性；
    
4. 而是去除覆盖；
    
5. 佛性功德最终完全显露。
    

这种路线容易产生强烈修行信心。

## 2. 实体化风险

若行者寻找：

- 一个永恒觉知；
    
- 不受条件影响的心体；
    
- 身心背后的真正主人；
    
- 纯净、常乐我的内在佛体，
    

上座部会认为修行已经从无我观转向细微我执。

## 3. 与上座部“心可净化”的差别

上座部也说：

- 心可修习；
    
- 烦恼可以断除；
    
- 心离五盖时明净；
    
- 阿罗汉心不再受污染。
    

但它不因此推导：

> 有一个从无始以来完整存在、只是等待显露的佛心实体。

# 十一、汉传天台止观

天台修行体系非常完整，不能只概括为“一念三千”。

## 1. 二十五方便

### 呵五欲

### 弃五盖

- 瞋恚
    
- 睡眠

### 调五事

- 饮食
    
- 睡眠

### 行五法

- 精进

这与上座部禅修前行存在明显共同基础。

## 2. 四种三昧

- 常坐三昧
    
- 常行三昧
    
- 半行半坐三昧
    
- 非行非坐三昧
    

## 3. 十境十乘观法

观察对象可以包括：

- 阴入界
    
- 烦恼
    
- 病患
    
- 业相
    
- 魔事
    
- 禅定
    
- 诸见
    
- 增上慢
    
- 二乘
    
- 菩萨境
    

十乘观法中包括：

- 观不思议境；
    
- 发真正菩提心；
    
- 善巧安心止观；
    
- 破法遍；
    
- 识通塞；
    
- 调道品；
    
- 对治助开；
    
- 知次位；
    
- 能安忍；
    
- 离法爱。
    

## 4. 一心三观

在一念中观察：

- 空
    
- 假
    
- 中
    

不是依次舍掉世俗而进入一个空无状态，而是：

- 见一切法无自性为空；
    
- 见因缘假名作用为假；
    
- 不执空有二边为中。
    

## 5. 与上座部的差别

天台的修行：

- 以菩提心和圆教佛果为终点；
    
- 以三谛圆融和一念三千为观慧结构；
    
- 容纳礼忏、诵经、三昧、观心等综合实践。
    

上座部则：

- 以四圣谛、三相和缘起为观慧结构；
    
- 不采用一念三千；
    
- 不把阿罗汉果列为需进一步超越的次位。

# 十三、禅宗修行完整结构

禅宗没有所有宗派统一的单一路线。

## 1. 基础部分

传统禅宗并非只靠一句“见性”，通常包括：

- 受戒；
    
- 僧堂生活；
    
- 作务；
    
- 坐禅；
    
- 经行；
    
- 亲近师家；
    
- 听法；
    
- 参问；
    
- 忏悔；
    
- 长期训练威仪和日常心行。
    

## 2. 默照路线

核心为：

- 身心安住；
    
- 不追随分别；
    
- 不压制念头；
    
- 寂而常照；
    
- 照而常寂；
    
- 不执有无、动静；
    
- 在一切活动中保持无取觉照。
    

与上座部可能对接：

- 正念正知；
    
- 舍；
    
- 不随烦恼；
    
- 观察念头自生自灭；
    
- 寂静与觉知并行。
    

差异：

- 默照常以本具觉性或佛性语言解释；
    
- 上座部会继续追问该“照”是否无常、缘生、无我；
    
- 单纯清明不执的状态不自动等于断结。
    

## 3. 话头禅

方法：

1. 生起大信根；
    
2. 生起大愤志；
    
3. 生起大疑情；
    
4. 持续参究“念佛是谁”“父母未生前本来面目”等；
    
5. 不以概念回答；
    
6. 疑团集中；
    
7. 疑情破裂；
    
8. 见性；
    
9. 由师家勘验；
    
10. 悟后保任和历事炼心。
    

与上座部不同：

- 上座部一般不以疑团集中作为主要定境；
    
- 不把无法以语言回答的突破体验本身视为漏尽；
    
- 会以结使是否断除、贪瞋痴是否消失、四谛是否现证来核验。
    

## 4. 公案禅

重点不是解决逻辑难题，而是：

- 打断惯性概念；
    
- 显露不二知见；
    
- 由师家逐则检验；
    
- 在语言、动作和境界中证明自在。
    

上座部没有公案课程和传法印证制度。

## 5. 顿悟与渐修

禅宗内部有不同解释：

- 顿悟顿修；
    
- 顿悟渐修；
    
- 渐修顿悟；
    
- 教悟与证悟的区别。
    

从上座部角度看，“突然洞见”并非问题；问题是：

> 洞见后是否已经不可逆地断除相应结使。

若仍有强烈贪欲、瞋恨、我慢和邪见，就不能只凭一次空寂或无念经验判为阿罗汉。

# 十四、汉传净土宗修行

## 1. 核心结构

常概括为：

- 信
    
- 愿
    
- 行
    

### 信

相信：

- 阿弥陀佛；
    
- 极乐世界；
    
- 佛的本愿；
    
- 念佛往生的可能。
    

### 愿

- 厌离娑婆；
    
- 欣求极乐；
    
- 发愿往生；
    
- 有些传统进一步发愿回入娑婆度众生。
    

### 行

- 持名念佛；
    
- 观想念佛；
    
- 观像念佛；
    
- 实相念佛；
    
- 礼拜、供养、诵经、持戒、放生、布施等助行。
    

## 2. 持名念佛次第

常见实践：

1. 确立信愿；
    
2. 持佛名号；
    
3. 摄耳谛听；
    
4. 妄念起时回归名号；
    
5. 形成连续净念；
    
6. 事一心不乱；
    
7. 理一心不乱；
    
8. 临终正念；
    
9. 蒙佛接引往生。
    

不同净土传统对“一心不乱”是否为必要条件看法不同。

## 3. 与上座部佛随念的共同点

- 重复忆念佛；
    
- 令心离散乱；
    
- 生信；
    
- 生喜；
    
- 减少恐惧；
    
- 临终保持善所缘；
    
- 形成强大善业。
    

## 4. 根本差异

上座部佛随念以：

- 佛德为所缘；
    
- 调伏五盖；
    
- 培养信心和定；
    
- 促成善趣及后续观修
    

为功能。

净土持名则通常进一步主张：

- 阿弥陀本愿；
    
- 他力摄受；
    
- 临终接引；
    
- 往生不退；
    
- 在净土继续完成佛道。
    

这不是同一种修法解释。

# 十五、汉传密教、唐密、东密和台密

共同结构大致为：

1. 寻找具资格阿阇黎；
    
2. 接受灌顶；
    
3. 受持三昧耶；
    
4. 学习坛城；
    
5. 结印；
    
6. 持真言；
    
7. 观想种子字、本尊和曼荼罗；
    
8. 修身密、语密、意密；
    
9. 使行者三密与佛三密相应；
    
10. 成就悉地或即身成佛。
    

## 与上座部护经、佛随念的差别

相似表面：

- 念诵；
    
- 佛像；
    
- 供养；
    
- 观想；
    
- 仪轨；
    
- 护佑。
    

结构差异：

- 上座部没有必须灌顶才能修习的本尊资格；
    
- 没有把手印、真言和观想视为佛三密的完整显现；
    
- 没有“自身即本尊”作为核心修法；
    
- 不以密教悉地和即身成佛为目标。

# 十六、藏传共同前行

藏传不同宗派虽有差异，但常见基础次第包括：

## 1. 暇满人身

观察：

- 获得人身的稀有；
    
- 能修法的自由和条件；
    
- 不应浪费生命。
    

## 2. 死亡无常

观察：

- 死亡必定；
    
- 死期不定；
    
- 临终只有法有真实利益。
    

## 3. 业果

- 善恶业不失；
    
- 行为、语言、思想会成熟；
    
- 应断十不善、行十善。
    

## 4. 轮回过患

观察六道痛苦，生起出离心。

## 5. 皈依

皈依：

- 佛
    
- 法
    
- 僧
    

密教中还可能包括：

- 上师
    
- 本尊
    
- 空行护法。
    

## 6. 菩提心

- 为一切众生成佛；
    
- 修慈悲；
    
- 自他平等；
    
- 自他相换；
    
- 七因果教授；
    
- 受菩萨戒。
    

这些与上座部的无常、业果、轮回过患、皈依、慈悲和戒有大量共同内容；主要差异在菩提心被规定为圆满道路的必需条件。

# 十七、藏传加行

许多藏传系统修共同或不共加行，例如：

- 十万大礼拜；
    
- 十万皈依；
    
- 十万金刚萨埵百字明；
    
- 十万献曼荼罗；
    
- 十万上师瑜伽。
    

目的包括：

- 净除业障；
    
- 积集福德；
    
- 建立传承信心；
    
- 软化我执；
    
- 为本尊法和心性教授作准备。
    

上座部没有以固定十万遍为标准的加行体系，也不以金刚萨埵或上师瑜伽净罪。

上座部净罪方式主要为：

- 认错；
    
- 忏悔；
    
- 防护未来；
    
- 如法恢复戒；
    
- 修善；
    
- 观察业果；
    
- 对不可撤销之业承担其果报。

# 十八、藏传止与观

## 1. 奢摩他

典型方法：

- 专注佛像；
    
- 专注明点；
    
- 专注呼吸；
    
- 无所缘安住；
    
- 九住心；
    
- 六力；
    
- 四作意；
    
- 身心轻安。
    

九住心通常为：

1. 内住
    
2. 续住
    
3. 安住
    
4. 近住
    
5. 调伏
    
6. 寂静
    
7. 最极寂静
    
8. 专注一境
    
9. 等持
    

这与上座部逐渐克服五盖、令心统一有功能相似。

## 2. 胜观

依不同宗派可能观察：

- 人无我；
    
- 法无我；
    
- 缘起性空；
    
- 心的明空；
    
- 一切显现如梦幻；

## 3. 止观双运

藏传通常强调：

- 仅有寂止不能断无明；
    
- 仅有分析而无稳定专注，智慧不坚固；
    
- 以轻安所摄的分析智成就特殊胜观；
    
- 最终止与观无分别运作。
    

这与上座部“定支持慧、慧断烦恼”的原则有共同点，但观察对象与哲学说明不同。

# 十九、藏传显教道次第

格鲁派道次第可概括为三士道。

## 1. 下士道

目标：避免恶趣，获得善趣。

修：

- 暇满；
    
- 死亡；
    
- 恶趣；
    
- 皈依；
    
- 业果。
    

## 2. 中士道

目标：个人出离轮回。

修：

- 苦谛；
    
- 集谛；
    
- 十二缘起；
    
- 戒定慧；
    
- 解脱心。
    

这一部分与上座部声闻道最接近。

## 3. 上士道

目标：为一切众生成佛。

修：

- 菩提心；
    
- 菩萨戒；
    
- 六度；
    
- 止观；
    
- 空性；
    
- 十地；
    
- 佛果。
    

上座部的异议集中在：

- 中士解脱不是暂时低级目标，而可以是究竟阿罗汉果；
    
- 不认为所有行者必须从中士转入上士；
    
- 不接受所知障和十地为阿罗汉之后的必经阶段。

# 二十、密教共同次第

## 1. 前提

传统上通常要求：

- 出离心；
    
- 菩提心；
    
- 空性正见；
    
- 一定戒律基础；
    
- 合格上师；
    
- 相应灌顶；
    
- 三昧耶。
    

因此，成熟藏传密教并不正式主张“完全不用戒定慧，只靠仪轨”。

## 2. 灌顶

灌顶可能包括：

- 宝瓶灌顶；
    
- 秘密灌顶；
    
- 智慧灌顶；
    
- 词句或第四灌顶。
    

其功能被解释为：

- 净化不同障碍；
    
- 授权相应修法；
    
- 植入或唤醒佛身语意种子；
    
- 建立密乘誓言。
    

上座部不承认灌顶具有这种解脱论地位。

## 3. 三昧耶

密教修行者除别解脱戒、菩萨戒外，还须守持密乘誓言。

上座部不接受秘密誓言凌驾于佛制戒律；若二者发生实际冲突，以上座部律判断行为。

# 二十一、生起次第

生起次第一般包括：

1. 观空；
    
2. 从空性中出现种子字；
    
3. 种子字转成本尊；
    
4. 自身成为本尊；
    
5. 环境成为坛城；
    
6. 观想本尊身相、庄严、手印；
    
7. 念诵心咒；
    
8. 光明放射、供养、摄受；
    
9. 收摄显现；
    
10. 本尊融入空性；
    
11. 再于日常显现中保持清净观。
    

## 修行目的

- 对治普通自我形象；
    
- 把身体、语言、思想训练为佛身语意；
    
- 观察一切显现如幻；
    
- 为死亡、中阴和再生作模拟；
    
- 为圆满次第准备稳定观想能力。
    

## 与上座部观想的比较

上座部也修：

- 佛德；
    
- 骨相；
    
- 尸体相；
    
- 遍相；
    
- 慈心遍满；
    
- 光明遍。
    

但关键差异是：

- 上座部不把自己认定为佛或本尊；
    
- 不建立清净佛慢；
    
- 不把坛城观想视为佛果因的专门密续结构；
    
- 观想最终仍须导向无常、苦、无我和离贪。

# 二十二、圆满次第

圆满次第往往涉及微细身：

- 脉（nāḍī）
    
- 气（prāṇa）
    
- 明点（bindu）
    
- 脉轮
    
- 拙火
    
- 大乐
    
- 细微心
    
- 幻身
    
- 光明
    

不同密续差异很大，不能当成一套固定课程。

典型目标是：

1. 令气进入、住于、消融于中脉；
    
2. 显露更细微心；
    
3. 以细微乐心证悟空性；
    
4. 成就幻身；
    
5. 结合光明和幻身；
    
6. 成就佛身。
    

## 与上座部的关系

上座部承认：

- 呼吸和身体状态影响心；
    
- 禅定会产生强烈喜乐和轻安；
    
- 身体可出现光明、震动、热感等；
    
- 高深定可能使身心活动极细。
    

但它不建立：

- 中脉作为证涅槃的必要通道；
    
- 明点作为佛果种子；
    
- 大乐空性作为最高捷径；
    
- 幻身和虹光身作为道果标准。
    

---

# 二十三、性瑜伽与戒律边界

这是不能含糊处理的部分。

## 1. 密教内部的理想解释

高级性瑜伽通常被解释为：

- 极少数高阶修行者的特殊方法；
    
- 必须具备灌顶、菩提心、空性见和控制气脉能力；
    
- 不是普通欲乐；
    
- 以俱生大乐显现细微智慧；
    
- 不得以贪欲为动机。
    

## 2. 上座部判断

对比丘而言，实际性交无论以何种观想、灌顶或见地进行，都构成波罗夷，不再具比丘身份。

所以，从上座部律角度：

> 不存在“证量足够便可合法以性交修道”的例外。

对在家人而言，上座部也不会把性行为列为证阿罗汉的必要或优越方法，而是以离欲、节制和观察欲乐过患为方向。

# 二十四、格鲁派无上瑜伽次第

格鲁派通常强调先完成：

1. 显教道次第；
    
2. 出离心；
    
3. 菩提心；
    
4. 空性正见；
    
5. 灌顶；
    
6. 生起次第；
    
7. 圆满次第。
    

圆满次第中可能涉及：

- 身远离；
    
- 语远离；
    
- 心远离；
    
- 幻身；
    
- 光明；
    
- 双运；
    
- 无学双运。
    

格鲁派不会把普通散乱意识称为究竟本觉，而重视中观应成空性见与极细心结合。

上座部仍不接受：

- 密续为佛说；
    
- 气脉次第是普遍解脱道；
    
- 佛果必须经幻身光明完成；
    
- 阿罗汉只断烦恼障而未究竟。

# 二十五、噶举派大手印

## 1. 常见准备

- 四共加行；
    
- 四不共加行；
    
- 上师瑜伽；
    
- 止；
    
- 观；
    
- 接受心性指示。
    

## 2. 四瑜伽

常概括为：

1. 专一
    
2. 离戏
    
3. 一味
    
4. 无修
    

### 专一

令心稳定，不随散乱。

### 离戏

见心和现象超越概念造作，不可实体化。

### 一味

各种经验在明空本性上同一味。

### 无修

不再刻意制造禅修状态，自然安住。

## 3. 与上座部的对照

“专一”近似定学，“离戏”可与无我观作比较，“不随念头”可与念住相近。

但不能直接等同：

- 大手印四瑜伽不是四道四果；
    
- 无修不等于阿罗汉无学；
    
- 心性指示不自动断除十结；
    
- “一味”不能被解释为善恶、戒犯和道果没有差别。

# 二十六、宁玛派大圆满

## 1. 前行

通常包括：

- 共同前行；
    
- 不共加行；
    
- 上师瑜伽；
    
- 灌顶；
    
- 三昧耶；
    
- 有时先修生圆次第。
    

## 2. 区分心与明觉

修行强调区分：

- 普通分别心（sems）；
    
- 明觉（rig pa）。
    

## 3. 彻却

大致指：

- 直接认出本初清净；
    
- 不修改、不追随、不压制念头；
    
- 念头起时在其本性中自解脱；
    
- 稳定认知；
    
- 融合坐上和座下。
    

## 4. 脱噶

涉及：

- 特定姿势；
    
- 凝视；
    
- 光明显现；
    
- 明点、光链、坛城等视觉经验；
    
- 四种显相的展开；
    
- 与虹光身理论相连。
    

## 5. 与上座部的关键差异

上座部会问：

1. 明觉是否仍属于缘生识？
    
2. 它是否具有生灭？
    
3. 是否可控制？
    
4. 是否应被认作我？
    
5. 认出明觉后，贪瞋痴是否实际断尽？
    
6. 光相是否只是定相或观染？
    
7. 是否仍须观照其无常和无我？
    

若把明觉解释为永恒独立的觉知主体，与无我冲突。

若只是指：

- 不执著；
    
- 清楚知道；
    
- 念头不起黏着；
    
- 当下洞见心不可得，
    

则可作现象学比较，但仍不能据此宣称与上座部阿罗汉道完全相同。

# 二十七、觉囊他空修法

觉囊传统尤其以时轮和他空见著名。

其修行可能包括：

- 显教菩提心；
    
- 止观；
    
- 他空见；
    
- 时轮灌顶；
    
- 六支瑜伽；
    
- 收摄、禅定、持气、随念、总持、三摩地等；
    
- 显现具足佛功德的胜义智慧。
    

上座部主要保留是：

- 胜义是否被解释为一个不空于自身、常住具德的心性；
    
- 微细身修法是否必要；
    
- 时轮佛果是否与四谛漏尽同一；
    
- 是否把现成本具功德置于实际断结之前。

# 二十八、萨迦道果

“道果”体系通常依喜金刚密续。

基本思想是：

> 轮回与涅槃的一切都完整具足于身心连续中，道通过修习使潜在佛果显露。

实践可能包括：

- 不净见；
    
- 瑜伽经验；
    
- 清净见；
    
- 灌顶；
    
- 本尊；
    
- 脉气明点；
    
- 四喜；
    
- 四灌顶；
    
- 道果见修。
    

上座部不接受这一密续架构，但可与之比较：

- 烦恼潜伏；
    
- 定暂时镇伏烦恼；
    
- 道智彻底断烦恼；
    
- 身心正是修行观察场域。
    

两者最大的区别是：

- 上座部不说佛果已经完整潜存于当前身心；
    
- 也不以大乐、灌顶和本尊作为令其显露的方法。

# 二十九、中阴与临终修法

## 1. 藏传中阴修行

可能包括：

- 生前熟悉死亡过程；
    
- 认识地水火风消融；
    
- 认识白显、红增、黑得；
    
- 认出死亡光明；
    
- 中阴中认出寂静、忿怒本尊；
    
- 破瓦迁识；
    
- 选择投生或净土。
    

## 2. 上座部临终修行

主要包括：

- 保持清醒正念；
    
- 忆念善业；
    
- 佛、法、僧随念；
    
- 慈心；
    
- 不执著亲属财产；
    
- 接受无常；
    
- 避免使临终者恐惧、愤怒；
    
- 以善所缘支持善速行和结生。
    

上座部阿毗达摩通常认为：

- 死心后紧接结生心；
    
- 不建立最长四十九日的中阴身阶段。
    

因此，中阴教学不是上座部修行的一部分。

# 三十、修行体验的跨传统误判

## 1. 光明

可能是：

- 上座部定相；
    
- 观染；
    
- 禅那光；
    
- 密教明点显现；
    
- 大圆满脱噶现象；
    
- 普通神经视觉现象。
    

不能仅凭“见光”判断传统果位。

## 2. 无念

可能是：

- 暂时没有明显语言思维；
    
- 强定；
    
- 昏沉；
    
- 舍；
    
- 禅宗无念；
    
- 大手印不追随念头。
    

无念不自动等于无明断尽。

## 3. 身体消失

可能发生于：

- 深度专注；
    
- 禅那；
    
- 感觉输入减弱；
    
- 身体边界感消失。
    

它不等于证无我，因为出定后仍可能执著“那个知道身体消失的我”。

## 4. 一切合一

可能是：

- 遍处定；
    
- 慈心遍满；
    
- 主客边界减弱；
    
- 华严式理解；
    
- 大手印一味体验。
    

上座部仍会观察：

- 此体验是否生灭；
    
- 是否受条件支配；
    
- 对它是否有贪爱；
    
- 它是否真正断结。
    

## 5. 极乐

可能来自：

- 初禅喜乐；
    
- 身心轻安；
    
- 信仰热情；
    
- 密教气脉；
    
- 情绪高峰。
    

乐受是无常的，不能以乐的强度判断解脱深度。

## 6. 空无

可能是：

- 无所有处；
    
- 昏沉；
    
- 感官撤退；
    
- 中观空性理解；
    
- 解离体验；
    
- 观察诸法不可得。
    

上座部会区别：

- 无所有处仍是有为定境；
    
- 涅槃不是一种“什么都没有”的感觉；
    
- 空性概念也不等于道智。

# 三十一、各传统果位核验方式对照

|传统|主要核验方式|
|---|---|
|上座部经藏|结使实际断除、四道四果、漏尽、无再生|
|《清净道论》系统|七清净、观智、道果心、省察断除之烦恼|
|泰国森林传统|贪瞋痴和无明根本被摧毁，不执著身、受、心乃至能知核心|
|中观|无自性见是否直接、稳定，并与菩提心和二资粮结合|
|唯识|能所二取是否破除，是否发生转依|
|天台|三谛圆融、一心三观及教观次位|
|禅宗|见性、师家勘验、悟后保任、境界中是否自在|
|净土|信愿持名、临终正念、往生瑞相或教义上的往生保证|
|密教|灌顶、三昧耶、生圆次第验相、气脉与本尊成就|
|大手印|心性认知及四瑜伽稳定|
|大圆满|明觉稳定、彻却脱噶显相、虹光身等传统标志|

这些核验标准不能无条件互换。

例如：

- 禅宗师家认可不等于上座部已断十结；
    
- 出现本尊验相不等于证入流；
    
- 见到禅相不等于认出大圆满明觉；
    
- 入第四禅不等于中观见道；
    
- 理解空性不等于阿罗汉漏尽。

# 三十二、可互相借鉴的方法

在不混淆理论和果位的前提下，以下方法可能具有跨传统价值：

## 1. 戒与生活简化

几乎所有传统都承认：

- 减少伤害；
    
- 减少欲望；
    
- 诚实；
    
- 节制；
    
- 稳定作息；
    
- 亲近善知识
    

有利修行。

## 2. 死亡无常

上座部死随念、藏传死亡观、净土临终准备都可帮助：

- 减少拖延；
    
- 放下世俗执著；
    
- 明确修行优先次序。
    

## 3. 慈悲

慈心、菩提心、自他相换和四摄法都可以对治：

- 瞋恨；
    
- 自我中心；
    
- 冷漠；
    
- 人际敌意。
    

但上座部不会因慈悲广大就把修行者直接判为高地菩萨。

## 4. 身体观察

- 上座部三十二身分、不净、四界；
    
- 禅宗威仪和身心一如；
    
- 密教身坛城和气脉；
    
- 藏传死亡消融观
    

都重视身体，但理论解释差异巨大。

## 5. 念头不跟随

上座部念住、禅宗默照、大手印和大圆满都可能教导：

- 念头出现时知道；
    
- 不压制；
    
- 不追随；
    
- 不认作我。
    

共同技术不能证明最终见地相同。

# 三十三、不能随意混修的部分

## 1. 无我观与常住真心

一边观察一切识无常无我，一边坚持某个永恒觉知就是自己，会造成方向冲突。

## 2. 上座部佛随念与本尊自生

前者忆念佛德；后者观自身即本尊。不能仅因都使用佛像和念诵就说是同一修法。

## 3. 四禅与气脉大乐

四禅依离欲、离不善法而生；气脉大乐的理论结构不同。身体愉悦相似不能证明证量相同。

## 4. 观智与中观推理

观生灭和哲学分析无自性可以互相启发，但不能把熟悉论证当作已生起坏灭智，也不能把观察刹那生灭自动当作圆满中观见。

## 5. 阿罗汉道与菩萨十地

两者终点、断障分类和发心结构不同，不应制造机械对应表。

## 6. 上座部戒与密教特殊行为

对上座部出家人，波罗夷等根本戒没有因密教灌顶而暂停的可能。

# 三十四、完整路线总览

## 路线一：上座部经典声闻道

皈依、信 → 持戒 → 根门防护 → 饮食知量 → 警寤 → 正念正知 → 远离 → 断五盖 → 四禅或足够定力 → 观察五蕴、六处、缘起 → 厌离离贪 → 四道四果 → 阿罗汉。

## 路线二：《清净道论》声闻道

戒清净 → 选择业处 → 近行／安止定 → 心清净 → 辨识名色 → 见清净 → 观察因缘 → 度疑清净 → 生灭观及辨认观染 → 道非道智见清净 → 坏灭等观智 → 行舍与随顺 → 道智果智 → 四果。

## 路线三：上座部菩萨道

成佛愿 → 佛前授记 → 十波罗蜜长期圆满 → 多生利益众生 → 最后一生出家 → 独自发现四谛 → 正等正觉 → 建立佛教。

## 路线四：印度大乘菩萨道

发菩提心 → 菩萨戒 → 六度四摄 → 止观 → 般若空性 → 资粮道、加行道、见道、修道、无学道 → 十地 → 二障净尽 → 佛果。

## 路线五：天台

二十五方便 → 四种三昧 → 十境十乘观法 → 一心三观 → 六即佛及菩萨位次 → 圆教佛果。

## 路线六：禅宗

戒与丛林训练 → 坐禅／话头／默照 → 身心集中或疑情 → 见性 → 师家勘验 → 悟后保任、历事炼心 → 佛道圆成。

## 路线七：净土

信 → 愿 → 持名或观想 → 净念相继 → 临终正念 → 往生净土 → 不退转 → 继续完成佛道。

## 路线八：藏传显教

暇满 → 无常 → 业果 → 轮回苦 → 皈依 → 出离 → 菩提心 → 六度 → 止 → 空性观 → 止观双运 → 十地 → 佛果。

## 路线九：藏传密教

显教共同道 → 上师与灌顶 → 三昧耶 → 加行 → 生起次第 → 圆满次第／气脉明点 → 光明、幻身或相应本宗高阶修法 → 双运佛果。

## 路线十：大手印

共同与不共加行 → 上师瑜伽 → 止 → 心性指示 → 专一 → 离戏 → 一味 → 无修。

## 路线十一：大圆满

共同与不共前行 → 灌顶及上师瑜伽 → 区分心与明觉 → 直接指示 → 彻却稳定 → 脱噶显相 → 法身圆满或虹光身传统目标。

从修行学角度，上座部对大乘、汉传和藏传不是简单地“全部拒绝”。

- 禅那喜乐与气脉大乐；
    
- 上座部菩萨波罗蜜与大乘六度十地。
    

## 上座部不会纳入自身道路的部分

- 阿赖耶识观；
    
- 一心三观；
    
- 事事无碍观；

- 中阴迁识；
    
- 大手印四瑜伽；
    
- 大圆满彻却脱噶。
    

## 与上座部发生原则冲突的部分

- 阿罗汉必须继续成佛；
    
- 以常住觉知为真实自我；
    
- 认为认出本觉即可取消断烦恼过程；
    
- 认为空性可以取消业果和戒律；
    
- 认为出家人可因高阶密法合法性交；
    
- 认为灌顶或师命高于佛制戒律；
    
- 把暂时光明、无念、喜乐或空寂直接认定为漏尽。
    

上座部最终坚持的修行判准是：

> 修行不是获得一种特殊身份、信念或体验，而是依戒、定、慧如实遍知苦，断除苦因，证悟涅槃，修成八圣道；其结果必须表现为相应结使不可逆地断除。
