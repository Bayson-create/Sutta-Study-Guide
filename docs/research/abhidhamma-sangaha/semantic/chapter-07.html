1. 四漏(cattāro āsavā)──欲漏(kāmāsavo)、有漏(bhavāsavo)、见漏(diṭṭhāsavo)、无明漏(āvijjāsavo)。各种烦恼中，「漏」(āsava＜ā向+ su(梵sru)流动﹐流向)《经集》、《法句经》、尼柯耶等常用「(诸)漏尽」(khīṇāsavo﹐khīṇāsavā)来表示解脱。「漏」有暗喻一股「流」之意，在佛教是用作「流出」，心中的污秽泄漏到外面。《杂阿含经》551经(T2.144.2)：「眼识起贪，依眼界贪欲流出(oka-sārī﹐流水)，故名为流。耳鼻舌身意流者，谓意识起贪，依意界贪识流出。故名为流。」在耆那教则是「流入」的意思，污秽从外面流入体内」附著于阿特曼(Atman)。总之，「漏」是佛教和耆那教所共用的。

在四漏当中，「欲漏」与「有漏」都是属于贪心所，「欲漏」是对五欲的流漏(DhsA.CS:p.402：pañcakāmaguṇasaṅkhāte kāme āsavo ‘kāmāsavo’.)，「有漏」是从色、无色的业，产生两种‘有’的流漏(Rūpārūpasaṅkhāte kammato ca upapattito ca duvidhepi bhave āsavo ‘bhavāsavo’)；「见漏」(Diṭṭhi eva āsavo ‘diṭṭhāsavo’)是邪见的漏，「无明漏」(Avijjāva āsavo ‘avijjāsavo’)是无明的漏。Vibhv.p.167︰Rūpārūpabhavesu chandarāgo bhavāsavo. Jhānanikantisassatadiṭṭhi- sahagato ca rāgo ettheva saṅgayhati.(于色、无色的欲染为「有漏」。此处收录具有常见的禅那欲求的染)。《中部》第九经《正见经》，舍利弗尊者说：「当漏生起，无明即生起」（āsavasamudayā avijjāsamudayo）「当无明生起，漏即生起。」（avijjā-samudayā āsavasamudayo）

《殊胜义》(Atthasālinī (PTS:#1099；CS:#1105)：「道的趣向中，须陀洹道断邪见漏，阿那含道断欲漏，阿罗汉道断有漏、无明漏。」(Maggapaṭipāṭiyā sotāpattimaggena diṭṭhāsavo pahīyati, anāgāmimaggena kāmāsavo, arahattamaggena bhavāsavo avijjāsavo cāti.)

2. 四暴(ㄆㄨˋ=瀑)流(cattāro oghā )：欲暴流 ( kāmogho )，有暴流 ( bhavogho﹐含色界染、无色界染 )，邪见暴流 ( diṭṭhogho )，无明暴流 ( avijjogho )。称为暴流（ogha），因为它们难以越渡。「四暴流」与「四漏」的内容相同。《法集论》中没详细列出。

3. 四轭( cattāro yogā )：欲轭(kāmayogo)，有轭 (bhavayogo﹐含色界染、无色界染)，见轭 (diṭṭhiyogo)，无明轭 (avijjāyogo)。轭（yoga），把有情套牢在轭中，难以逃脱。「四轭」与「四漏」的内容相同。

4. 四系 ( cattāro ganthā )──贪身系 ( abhijjhā kāyagantho )、嗔身系( vyāpādo kāya-gantho )、戒禁取身系( sīlabbataparāmāso kāyagantho )、此实执取身系(idaṁsaccābhiniveso kāyagantho )。系 ( gantha )有系属、绑住之意，四种系中，「戒禁取身系」是执著仪式能导致解脱，(如牛戒、狗戒)，「此(idaṁ)实(sacca)执持(abhiniveso)身系(kāyagantho)」是执取「只有这个才是真实的」信仰，而别的见解都是错的。

5. 四取 ( cattāro upādānā )──欲取 ( kāmupādānaṁ )、见取( diṭṭhupādānaṁ )、戒禁取 ( sīlabbatupādānaṁ )、我语取 ( attavādupādānaṁ )。四取当中，「欲取」是对欲乐的渴爱，诸注疏说欲取包括对一切世间之物的渴爱。「见取」是执取错误的见解，例如常见、断见等，或臆度「世界是永恒的？还是不永恒的？」等。在《长部》《梵网经》里，佛陀举出有关「我」与「世界」的六十二种邪见。「戒禁取」是认为执著实行仪式，或以为修苦行或修种种不当的戒禁能够导向解脱。

「我语取」即「身见」（sakkāyadiṭṭhi），即认为五蕴的任何一个是「我」或「我所有」。经典里提出了二十种身见，例如：「色蕴是我，或我拥有色蕴，或色蕴是在我里面，或我在色蕴里面」，对于受蕴、想蕴、行蕴、识蕴也是如此（见《中部》M.44经）。

6. 六盖 ( cha nīvaraṇāni )──欲欲盖 ( kāmacchanda-nīvaraṇaṁ )、嗔盖( vyāpāda-nīvaraṇaṁ )、惛沈.睡眠盖 ( thīnamiddhanīvaraṇaṁ )、掉举.恶作盖 ( uddhaccakukkucca-nīvaraṇaṁ )、疑盖(vicikicchānīvaraṇaṁ )、无明盖 ( avijjānīvaraṇaṁ )。「盖」是阻碍通向善趣与涅槃之道。经典说盖是阻碍善法的生起，也使已生起的善法消退。前五盖障碍正念、禅那的生起，无明盖则障碍智慧的生起。论注解释昏沉.睡眠、掉举.恶作合为一是因为它们有类似的作用、缘与对治它们的方法。昏沉与睡眠使名法软弱无力的作用，它们是缘于懒惰与昏睡，对治它们的方法是精进。掉举与恶作都有导致不安的作用，它们是缘于困扰的念头，对治它们的方法是修定。《长部注》(DA.1./I,59.))说：「许多的五盖(puthu pañcahi nīvaraṇehi)已覆盖(āvutā)、已包围(nivutā)、已覆障(ovutā)、已关上(pihitā)、已隐藏(paṭicchannā)、已遮没(paṭikujjitāti)称为凡夫(puthujjanā)。」

7. 七随眠(satt’ānusayā )：一、欲染随眠 ( kāmarāgānusayo欲界贪，五官的欲望 )，二、有染随眠 ( bhavarāgānusayo含色界染、无色界染 )，三、嗔随眠 ( paṭighānusayo )， 四、慢随眠 ( mānānusayo )， 五、见随眠 ( diṭṭhānusayo )，六、疑随眠 ( vicikicchānusayo ) ，七、无明随眠 ( avijjānusayo )。随眠(=使)，即潜在倾向（anusaya），是「潜伏」（anusenti< anu随+si(梵śī)眠﹑卧）的烦恼，每当诸缘具足时即会产生困扰。

8. 经说十种结 ( dasa saṁyojanāni )：一、欲染结 ( kāmarāga-saṁyojanaṁ )，二、色染结 ( rūparāga-saṁyojanaṁ )，三、无色染结 ( arūparāga-saṁyojanaṁ )，四、嗔恚结( paṭigha-saṁyojanaṁ反击结) ，五、慢结 ( māna-saṁyojanaṁ )，六、邪见结 ( diṭṭhi-saṁyojanaṁ )，七、戒禁取结( sīlabbataparāmāsa-saṁyojanaṁ )，八、疑结 ( vicikiccha-saṁyojanaṁ )，九、掉举结 ( uddhaccasaṁyojanaṁ )，十、无明结 ( avijjāsaṁyojanaṁ )。结(saṁyojana)有绑住、系缚生死之意。

9. 论说十种结 ( dasa saṁyojanāni )：一、欲染结( kāmarāga-saṁyojanaṁ )；二、有染结(bhavarāgasaṁyojanaṁ，含色界染、无色界染)；三、嗔恚结（paṭigha-saṁyojanaṁ 反击结）；四、我慢结( māna-saṁyojanaṁ )；五、邪见结( diṭṭhi-saṁyojanaṁ )；六、戒禁取结( sīlabbataparāmāsa-saṁyojanaṁ )；七、疑结( vicikiccha-saṁyojanaṁ )；八、嫉结(issāsaṁyojanaṁ)；九、悭结(macchariya-saṁyojanaṁ)；十、无明结(avijjāsaṁyojanaṁ)。

10.十污染 ( dasa kilesā )──贪 (lobho)、嗔( doso )、痴( moho )、慢( māno )、见( diṭṭhi )、疑( vicikicchā )、惛沈( thīnaṁ )、掉举( uddhaccaṁ )、无惭( ahirikaṁ )、无愧( anottappaṁ )。污染( kilesa, 梵语 kleca )：众生为自我的欲望，常招受恼害，致使身心发生烦、恼、乱、迷、惑、污染等问题。一般以贪、嗔、痴三惑为一切烦恼之根源，有时称作漏、暴流、轭、系、取、盖、随眠、结、缠（pariyuṭṭhāna现行烦恼）、缚（bandhana）、执著(anugiddha)、垢(mala尘垢)、颠倒(vipariyāsa)、戏论(papañca)、心秽(cittassa upakkileso)、客尘(āgantuka)等名称。

2. 七禅支（satta jhānaṅgāni）：寻、伺、喜、一境性、悦、忧、舍。在此，「禅那」(jhāna)与禅定的用法不同，发生在禅定之外。「禅支」在此有「所谓的靠近所缘而考虑、思想之意。根据情况，又有燃烧(五)盖之意，及已升起诸禅支之意，以要素成份之意，被称为‘诸禅支’。」(Ārammaṇaṁ upagantvā cintanasaṅkhātena upanijjhāyanaṭṭhena yathārahaṁ paccanīkadhammajhāpanaṭṭhena ca jhānāni ca tāni aṅgāni ca samuditānaṁ avayavabhāvena aṅgīyanti ñāyantīti jhānaṅgāni.)(《广释》(Vibhv.PTS:p.170；CS:p.221~2)其中的「忧」是不善法。其余六个可以是善、不善或无记。

5. 二十二根

五根是指五净色；命根有两种：名命根与色命根。

未知当知根（anaññātaññassāmītindriyaṁ我将知未知根）是：与须陀洹道心（善心）相应的慧心所。

  已知根（aññindriyānīti）是：与须陀洹果（果心）、斯陀含道（善心）、斯陀含果（果心）、阿那含道（善心）、阿那含果（果心）、阿罗汉道（善心）等六个出世间心相应的慧心所。

具知根（aññātāvindriyaṁ）：是与阿罗汉果（果心，无记）相应的慧心所。古译诸经论中，「具知根」(aññātāvindriyaṁ)，有时误译作「无知根」。aññā：了知、已知、开悟，aññāṇa(a-ñāṇa)才是无知。

★ 注意︰「疑心」的「一境性」达不到‘根’（换言之，疑心的根缘没有一境性）。

增上法是支配俱生名聚实行或完成艰难或非常重要的任务的心或心所。

★ 注意︰同一个名聚只能生起一种增上法，且增上只出现于二因或三因速行。

 　本品导读

◙ 前六品分别解说了阿毗达摩的八十二个究竟法。本品则集结经藏中常出现的基本术语，七十二种有自相的基础法，并以阿毗达摩式的分类法，将它们分门别类。首先，依「不善、杂、菩提分及一切法」，将它们归纳为四大类，然后再分别解说它们相等于哪一个究竟法。

◙ 本品【表解】依上述分类法，列举诸法及其相对应的心所。读者应熟悉与「杂」项有关的各种究竟法(尤其是标示★)，它们将于第八品之发趣法中被涉入，作为缘法。

  本品导读 -- 重点整理

一、摄不善

1. 九项：四漏、四暴流、四轭、四系缚、四执取、六盖、七随眠、十结、十烦恼。

2. 涵盖14种不善究竟法，即：14不善心所，包括：痴、无惭、无愧、掉举、贪、 邪见、慢、嗔、嫉、悭、恶作、昏沉、睡眠、疑。

二、摄杂

1. 七项：六因、七禅支、十二道支、二十二根、九力、四增上、四食。

2. 涵盖36种究竟法，包括：1心、26心所（10通一切心所、6不善心所、

10善心所）、9色法。

三、摄菩提分（‘菩提分’为「觉悟的成份」，资益觉悟之意(Pts.II,115.)）

1. 七项：四念处、四正勤、四神足、五根、五力、七觉支、八道支。

2. 涵盖14种究竟法，包括：心、受、一境性、寻、精进、喜、欲、信、 念、轻安、正语、正业、正命、慧

四、摄一切*

1. 五项：五蕴、五取蕴、十二处、十八界、四圣谛。

2. 涵盖89心、52心所、28色、涅槃

﹝结劝﹞

(一)应知的法︰一、不善。二、杂。三、菩提分。四、一切法。

      (二)应断的法︰一、不善--四漏等

二、杂--六因中的「贪、嗔、痴」

                          七禅支中的「忧」

十二道支中的「邪见、邪思惟、邪精进、邪定」

二十二根中的「忧根」

九力中的「无惭力、无愧力」

三、一切法中的「五取蕴」(「取」为执取、执著)

      (三)应证的法︰涅槃

      (四)应修的法︰菩提分

*《杂阿含319经》︰「一切者，谓十二入处：眼、色，耳、声，鼻、香，舌、味，身、触，意、法，是名一切。」(cf. S.35.23.Sabba一切)一切：sabbam。印度哲学sarvam与「世界」、「宇宙」等含义相同。
