〈1.摄心分别品〉解答

( 1 ) 1.能体验(或知道)目标(或所缘)的究竟法是：1.心与心所 2.色法 3.涅槃 4.以上皆是

（说明：任何究竟法都可以作为目标，但只有心与心所能体验所缘，心与心所不必与色法俱起）

( 2 ) 2. 「忧心忡忡」是：1.果报心  2.不善心  3.无因心  4.以上皆是

（说明：「忧心忡忡」(心的忧受)一定是嗔心，它们是有因(嗔、痴)的不善心）

( 1 ) 3. 身体的「苦受」是：1.果报心  2.不善心  3.有因心  4.以上皆是

（说明：身体的「苦受」一定是无因不善的果报心，它是不善的结果，但不是造业的不善心）

( 4 ) 4. 舍俱推度心是：1.欲界心  2.果报心  3.无因心  4.以上皆是 

( 1 ) 5. 心分为八十九种是因为：1.整理的结果  2.法尔如是(原来就如此)  3.经典所说

（说明：经典没有说到八十九心(ekūnanavuti cittāni)，这是阿毗达摩使用的名词）

( 1 ) 6. 善眼识不是：1.善心  2.无因心  3.舍受  4.欲界心

（说明：善眼识是欲界无因舍俱善果报心，因此不是善心。）

( 4 ) 7. 无因唯作心：1.不是某因的果报 2.不会产生果报 3.没有无贪.无嗔.无痴 4.以上皆是

（说明：唯作心是既非会产生果报的善与不善心，亦非果报心；而无因表示既无贪嗔痴的因，亦无无贪.无嗔.无痴的因。）

( 4 ) 8. 「果报心」是：1.无记  2.不是造业的心  3.有取对象(所缘)  4.以上皆是

1. 无因果报心与有因果报心有何差别？

答：一、无因果报心不含无贪、无嗔、无痴之因子，也不含贪、嗔、痴之因子。

无因果报心有15个，分两组：7无因不善果报心，与8无因善果报心。

二、有因果报心含无贪、无嗔、无痴之二因或三因的因子。

有因果报心有21个，包括：欲界八大果报心、色界五果报心、无色界四果报心、四出世间果心。

三、无因果报心与有因果报心执行的作用不同(详见第三品)。

2. 欲界善心与不善心会产生什么果报心？

答：欲界八大善心可以产生的果报心分无因与有因两种，无因善果报心有8个，包括：

1眼识(舍俱)、2耳识(舍俱)、3鼻识(舍俱)、4舌识(舍俱)、5身识(乐俱)、6舍俱领受、7舍俱推度、8悦俱推度；以及有因善果报心有8个，包括：悦俱智相应心2个、悦俱智不相应心2个、舍俱智相应心2个、舍俱智不相应心2个。

欲界十二种不善心可以产生的果报心只有无因不善果报心有7个，包括：1眼识(舍俱)、2耳识(舍俱)、3鼻识(舍俱)、4舌识(舍俱)、5身识(苦俱)、6舍俱领受、7舍俱推度。

3. 阿罗汉为什么不造善业、恶业？

答：阿罗汉已断所有的烦恼(包括潜在的烦恼)，已没有恶业的潜力(不善思)；在心中尚具有「美心所」(sobhana cetasika﹐有25个)，但已没有善业的潜力。阿罗汉能生起的心包括唯作心、果报心与出世间心。

4. 生在欲地可以生起色界心或无色界心吗？色地众生可以生欲界心或无色界心吗？

答：(三因)欲地众生得初禅乃至第五禅即生起色界心，由第五禅起修空无边处等即是生无色界心。色地众生可以生欲界心，若修无色禅即生无色界心。

5. 有行心与无行心有何差别？

答：「无行」（asankhārika）即没有受自己或他人的怂恿或鼓励。

「有行」（sasankhārika）即受到自己或他人怂恿或刺激，才生起的心。

有行心与无行心存在于欲界八大善心、欲界八大果报心、欲界八大唯作心，及欲界不善心的贪心、嗔心中，色界心与无色界心则无此分别。

6. 89心与121心的差别如何？

答：「89心」中含有8个出世间心。

「121心」中含40个出世间心，详分初禅至第五禅所得到的道心、果心。(89-8+40=121)

7. 阿罗汉微笑时，生什么心？

答：欲地或色地阿罗汉生欲界心，微笑时，只能取欲界所缘，生起的心有五种可能：

一、(阿罗汉)生笑心（hasituppādacitta）。二、悦俱.智相应.无行。三、悦俱.智相应.有行。四、悦俱.智不相应.无行。五、悦俱.智不相应.有行。

无色地的阿罗汉没有身体，所以没有「(阿罗汉)生笑心」。

8. 生气时，生起什么心？

答：主动生气是忧俱.嗔恚相应.无行；受别人的刺激，被动生气是忧俱.嗔恚相应.有行。

9. 列举无因心。

答：有十八无因心，包括：1五门转向心，2眼识2耳识2鼻识2舌识2身识，2领受心，3推度心，1确定心，1生笑心。

10. 请求（okasa乞请）别人帮助（善事）的心是善是恶？(课外题)

答：请求心有时是善，有时是恶。善的时候，是散发慈心给被请求的人，请别人布施恩惠，若不遂所愿，不会失望、痛苦。

请求心有渴望(贪)时，是属于不善的，其时心不平静；若不遂所愿，心情是失望、痛苦。

〈2.摄心所分别品〉解答

( 3 )1. 与「不善眼识」共存的「受心所」是：1.善 2.不善 3.无记

（说明：13通一切心所(包括受心所)，它们的本性（善、不善、无记）是决定于与它共存的心或心所，在善心里它们即是善，在不善心里它们即是不善，在无记心里，即变成无记。眼识是果报心，不论是善或不善果报心皆是无记，因此与眼识共存的「受心所」是无记。）

( 2 )2. 美心所不会是：1.善　2.不善　3.果报  4.唯作

（说明：(二十五种)美心所可以是善、果报、唯作，视与它共存的心与因而定，但美心所不会是不善。）

1. 不善心出现时，同时具有几个不善心所？

答：不善心有共14个「不善心所」，而能同时出现的不善心所有4~8个。

2. 正语、正业、正命出现于何时？

答：在决定不说妄语时（离妄语），或讲真实语时，生起「正语」心所；

决定不做杀、盗、淫时（离邪业），或做正当的行为时，生起「正业」心所；

决定不作非法的经济活动时（离邪命），或做正当的经济活动时，生起「正命」心所。

在「世间心」中，正语、正业、正命，不是不出现，就是只出现一个，不能同时出现两个或三个。若是知道因果（有慧），则生起「念」与「慧」心所之外，有时还会生起三离心所之一。证道时（以涅槃为所缘），三离心所同时生起，称为「正断离」(samucchedavirati)。

3. 列举七遍一切心心所。

答：触、受、想、思、一境性、命根、作意。

4. 列举没有精进心所的心。（可查阅表格，不需死记）

答：1五门转向＋15无因果报心（＝10双五识+2领受+3推度）。

5. 列举没有遍一切不善心心所的心。

▓三果圣者欲界死后，投生上界后，不必加行，断五上分结而般涅槃，为「无行般涅槃」(asasaṅkhāra-parinibbāna)。

▓三果圣者欲界死后，投生色界初禅天，渐次上生至色究竟天，于其间久时乃断五上分结而般涅槃，(往)上流阿迦腻咤般涅槃(Uddhaṁ soto akaniṭṭhagāmī (=uddhaṁsoto hoti akaniṭṭhagāmin)﹐akaniṭṭha，阿迦腻咤(即色究竟天))。

答：前一世的「死心」生起灭尽后，连接下一世的「结生心」立即生起，中间并无中阴身。

9. 阿罗汉的临终速行心取何目标？(课外题)

答：阿罗汉的临终速行心，可以取禅那的目标(佛陀是取第四禅那为目标，见《长部》大般涅槃经,D.16./II,156.)，或者任何目标(理论上，甚至于包括曾作的恶业目标)；但不会入果心(phalasamāpatti,以涅槃为所缘)而死。阿罗汉也不会入灭尽定而死。

10. 如何判断众生是否命根断？(课外题)

答：众生若还有呼吸，表示还活著，因为要动心念才能呼吸，呼吸不会自然、无因无缘地进行。有七种众生不呼吸(但命根未断)，即：「1在母胎中（的胎儿）无（出入息），
2潜入水中的人无，3如是无想天人(asaññībhūtānaṁ)，4死者，5第四禅的入定者，6生居于色及无色界者，7入灭尽定者。」(《清净道论》Vism.283.)其他如晕厥者也暂无呼吸。众生若命根断，身体就会腐烂(只剩时节生色)。修习过「名业处」者，可观察欲界众生的心(有分心)，若还存在于心脏，则命根未断。入灭尽定者，没有心，也没有心生色，但是其余的三种色法还在(业生色、食生色、时节生色)。

植物人并没有死，因为他(她)还有呼吸。

       刚「死亡」者，最好放几小时或几天，确定已死(如身体腐烂)，才处理后事，以免误事。

10. 如何对治「疑」心？（课外题）

答：在阿毗达摩中，「疑」只作对因果、佛法僧的疑，不能解作对一般事务的疑惑、困惑。否则须陀洹道就无法断「疑」。

消除疑心的方案，以思惟方式来说，A.1.2./I,4.︰「诸比丘！我不见别有一法，能生未生之疑，或能增广已生之疑。诸比丘！此即不从根源作意(ayonisomanasikāro)。」A.1.2./I,5.︰「诸比丘！我不见别有一法，能不生未生之疑，或能断已生之疑，诸比丘！此即如理思惟(yonisomanasikāro)。」

以教理来说，需要研读经典，或更深究(paripucchā遍问)三藏。换句话说，「疑」可以用「慧」或「择法觉支」来对治。而《清净道论》(Vism.141)说：vicāro vicikicchāyāti  Peṭake vuttaṁ.(在《彼多迦》(Peṭaka)中说：‘伺’对治‘疑’。「伺」因为以「智慧」考察再考察(伺)，所以可以对治「疑」。注释书还提出六法断疑：1.多闻正法(bahussutatā)，2.深究正法(paripucchakatā遍问)，3.于戒律上知取舍(vinaye pakataññutā)，4.强化信仰(adhimokkhabahulatā)，5.亲近善友(kalyāṇamittatā)，6.适当的谈话(sappāyakathā)。(DA.22./III,782.；AA.1.2./I,51.；Spk:S.46.51./III,167.etc.)

以实修来说，达到第二观智(度疑清净)才能暂时去除「疑」，达到证果则永断「疑」根。

1. 列举二十四缘中，「五门转向」生起，不须依靠何种缘？并说明原因。

答：五门转向生起，不须依靠６种缘，包括：

1.因缘：只有有因名聚才须依靠因缘，而五门转向是无因名聚。

2.增上缘：只有速行名聚才须依靠增上缘，而五门转向不是速行名聚。

3.后生缘：所有的名聚皆不须依靠后生缘。

4.重复缘：只有速行名聚才须依靠重复缘，而五门转向不是速行名聚。

5.道缘：只有有因名聚才须依靠道缘，而五门转向是无因名聚。

6.果报缘：只有果报名聚才须依靠果报缘，而五门转向不是果报名聚。

※上述各项也适用于「确定名聚」。

2. 列举二十四缘中，「眼识」生起，不须依靠何种缘？并说明原因。

答：眼识生起，不须依靠６种缘，包括：

1.因缘：只有有因名聚才须因缘，而眼识是无因名聚。 

2.增上缘：只有速行名聚才须增上缘，而眼识不是速行名聚。

3.后生缘：所有的名聚皆不须后生缘。

4.重复缘：只有速行名聚才须重复缘，而眼识不是速行名聚。

5.道缘：只有有因名聚才须道缘，而眼识是无因名聚。

6.禅那缘：只有双五识不须禅那缘。

※上述1~5项亦适用于领受心与推度心，它们不须依靠5缘。

3. 列举二十四缘中，「贪名聚」生起，不须依靠何种缘？并说明原因。

答：贪名聚是速行名聚，速行名聚生起，至少不须依靠２种缘，包括：

１.后生缘：所有的名聚皆不须后生缘。

2. 果报缘：只有果报名聚才须果报缘，而贪名聚不是果报名聚。

3. 若是第一个速行名聚，则不须重复缘。

※上述适用所有五门名聚路的贪速行、嗔速行、大善速行、大唯作速行。

若是痴速行则另加增上缘；若是无因生笑速行则亦另加因缘＋增上缘＋道缘。

4. 列举二十四缘中，「无因第2彼所缘」生起，不须依靠的缘？并说明原因。

答：无因彼所缘是3舍俱推度名聚之一，因此生起不须依靠5种缘，包括：

1.因缘：只有有因名聚才须因缘，而无因彼所缘是无因名聚 。

2.增上缘：只有速行名聚才须增上缘，而彼所缘不是速行名聚。

3.后生缘：所有的名聚皆不须后生缘。

4.重复缘：只有速行名聚才须重复缘，而彼所缘不是速行名聚。

5.道缘：只有有因名聚才须道缘，而无因彼所缘是无因名聚。

※上述亦完全适用于执行推度作用的「推度名聚」。

5. 列举二十四缘中，心生色生起或继续存在，不须依靠的缘？并说明原因。

答：包括心生色在内的色聚生起或继续存在，至少皆不须依靠９种缘，包括：

1~6 无间组缘：无间缘、等无间缘、亲依止缘、无有缘、离去缘、重复缘。

　　　　　　　只有名聚才须依靠无间组的缘。

7.所缘缘：所有色聚都不能取任何所缘。

8.前生缘：所有色聚都不依靠前生缘。

9.相应缘：所有色聚皆不依靠相应缘。

其他则视产生心生色的俱生名聚而定，譬如：

一、五门转向与确定之心生色，除不须上述９缘外，亦不须：因缘、果报缘、道缘、增上缘。

二、领受与推度之心生色，除不须上述９缘外，亦不须：因缘、道缘、增上缘。

三、所有速行之心生色，除不须上述９缘外，亦不须：果报缘。

四、有因彼所缘之心生色，除无上述９缘外，亦不须：增上缘。

2. 十二缘起中的「有」，「业有」（kammabhava）与「生有」（upapattibhava）的差别？

答：「缘于‘取’，‘有’生起」：‘有’（存在）有两种：‘业有’与‘生有’。

「业有」指过去世的善与不善思（29种=12不善心+8善心+5色界善心+4无色界善心）。

「生有」是指32种果报心（=7不善无因心+8善无因心+8善果报心+5色界果报心+4无色界果报心）、及其各自的相应心所与业生色。

3. 「行蕴」、「无明缘行」的「行」及「诸行无常」的「诸行」有何不同？

答：一、「行蕴」（saṅkhārakkhandha）是指五十二心所法当中，除去受蕴与想蕴，其余的五十心所。有时说「行」即五蕴(Saṅkhārāti pañcakkhandhā)(DhA.CS:p.2.240)。

二、十二缘起支里的「行」(saṅkhāra)是指善心与不善心里的「思」心所--造业的主要心所。《清净道论》说：Saṅkhārā paṭisandhiyaṁ pakkhipanato aṅgārakāsuyaṁ khipanakapurisā viya.(‘行’，(把人)丢入结生，好像把人丢入炭火。)(Vism.489)，可见「行」具有投胎的力量。(古代译经家，有时直接把「行蕴」译成「生死」)。

三、「诸行无常」的「诸行」(saṅkhārā)，是指「行法」(saṅkhāradhamma)、「有为法」(saṅkhatadhamma)，即因缘和合之法。

4. 列举「不离去缘」可再细分为哪些缘？

答：1.俱生不离去缘、2.所缘前生不离去缘、3.依处所缘前生不离去缘、4.依处前生不离去缘、5.后生不离去缘、6.色食不离去缘、7.色命根不离去缘。

5. 列举「相互缘」出现的情况。

答：【心或任何相应心所】与〔同一名聚里其余（心与）心所〕彼此互作为「相互缘」。

〔四大〕之间彼此互作为「相互缘」。

2. 如何对治贪？有哪些业处适合贪行者？

答：从根源作意(如理作意)能断贪。A.1.2./ I,2.︰「诸比丘！我不见别有一法，使生起未生之欲，或增广已生之欲。诸比丘！此即是净相(subhanimittaṁ)。诸比丘！不从根源作意(ayoniso manasi karoto)净相者，使生起未生之欲，或增广已起之欲。」A.1.2./ I,4.︰「诸比丘！我不见别有一法，不使生起未生之欲，或断已生之欲。诸比丘！此即是不净相(asubhanimittaṁ)。诸比丘！从根源作意(yoniso manasi karoto)不净相者，使不生起未生之欲，或断已生之欲。」

一切业处都适合贪行者使用，但是对治贪的业处有：十不净、三十二身分。

3. 如何对治嗔？有哪些业处适合嗔行者？

答：慈心解脱(mettā cetovimutti, AA.1.2./I,47.︰对一切有情徧满祝福的慈)是如何对治嗔有力的方法。A.1.2./I,3.︰「诸比丘！我不见别有一法，使生起未生之嗔，或增广已生之嗔。诸比丘！此即是嗔恚相(paṭighanimittaṁ)。诸比丘！不从根源作意嗔恚相，使生起未生之嗔，或增广已起之嗔。」A.1.2./I,4.︰「诸比丘！我不见别有一法，不使生起未生之嗔，或断已生之嗔。诸比丘！此即是慈心解脱。诸比丘！从根源作意慈心解脱，使不生起未生之嗔，或断已生之嗔。」

一切业处都适合嗔行者使用，但是对治嗔的业处有：止禅--青遍、黄遍、赤遍、白遍(专心于一片颜色而止息嗔恚)，慈无量心、悲无量心、喜无量心、舍无量心。

5. 如何消除昏沉.睡眠盖？如何究竟断除昏沉.睡眠盖？

答：一、消除昏沉.睡眠盖：

1.身语意清净，不作诸恶，具足正念，就没有含有贪、嗔的「有行心」(昏沉.睡眠盖)。

2.睡前作意。佛告诸比丘：『若汝洗浴竟欲眠，当作是念：我发未燥当起，如是眠若夜亦应知，时月至某处当起，若无月，星至某处当起，当念佛为初，于十善法(dasasu kammaṭṭhānesu于十业处)中，一一法中随心所念然后眠。』(《一切善见律毗婆沙》﹐T.24.759.3；《普端严》Sp.Pārā.III,518.)

3.得禅那，可镇伏五盖。

4.修光明想。《清净道论》(Vism.132)：「以光明想而作意，变换威仪及露地住而习行等，除去其惛沉和睡眠。」

5.‘寻’对治‘惛沉睡眠’(vitakko thinamiddhassa.)(《清净道论》(Vism.141)引用Peṭaka)。

  ‘寻’即正思惟，或背诵经典，讨论法义等。

二、究竟断除昏沉.睡眠：欲界贪、嗔含有「有行心」，也就是昏沉.睡眠；要断欲界(下界)贪、嗔，则须证得三果(断五下分结)。

《解脱道论》卷第四：「睡眠者，谓身闷重，欲得寤寐。眠有三种：一从食生。二从时节生。三从心生。若从心生以思惟断，若从饮食，及时节生，是罗汉眠不从心生无所盖故。若眠从食及时节生者，以精进能断。如阿楼驮所说：我初尽漏得不从心眠，于今五十五岁，于其中间断食、时节，卧已二十五年。」(T32.416.2)

6. 睡觉前适合修习什么业处？

答：1.修习呼吸法是很好的睡前业处。若呼气时加强放松，有助于入眠。

2.作光明想(ālokasaññā)。《中阿含经》说：「右胁而卧，足足相累，作光明想，立正念正智，常作起想。」（T1.552.2）《相应部注》SA.51.20./III,260.：「善持光明想：若比丘在空旷地坐好，时而闭眼时而开眼，作光明想。那时闭眼(光明)就好像开眼一样存续，此时即生起光明想。」专注于月光，或不摇晃的灯光，或照在地上的光，或穿过墙缝照在另一道墙上的光线，作为修习光明遍的目标。

7. 既非修止禅（samatha），也非修观禅（vipassanā）的心是什么？

答：既非修止禅，也非修观禅的心，可能是欲界恶心(pāpako, akusalacitto)，或欲界善心，或掉入有分心，或唯作心，或入世出世间禅那，或已入无心定，或第五禅的神通心。神通心是属于止禅的范畴。

8. 初禅为什么会出现五禅支？

答：寻伺--因为一直运作寻、伺，结果产生强劲的寻、伺。

    喜--一直运作寻伺，而且成功达成寻伺专一的目标，心无其他的杂染，所以有欢喜。

    乐--欢喜于目标，而产生快乐。身体也会心里的喜乐而百脉舒畅，所以有身乐。

    一境性--当心专注、无杂乱时，就完全专注。若修止禅，则把心投入禅相。若修观禅，则把心投入目标的生灭相等。

9. 止禅（samatha）与观禅（vipassanā）有何差别？（课外题）

答：止禅(samatha奢摩他)是：sama平息 +-atha (名词语基)。止禅是修习业处(kammaṭṭhāna工作的处所)，在一个对象(ārammaṇa所缘)培育专注力，紧密地观察（upanijjhāyana）对象，平息心的犹豫或不安定，伴随五禅支(vitakkavicārapītisukhekaggatāsahitaṁ寻、伺、喜、乐、一境性)，而得到近行定(upacāra samādhi﹐靠近禅那的定力，已具有五禅支，但不稳定，还会掉入有分心或生起五盖)或安止定(appaṇā samādhi﹐完全的专注，镇伏了五盖，反复地生起七个安止速行心)。在安止定中，无法生起观智(ñāṇadassana)。

观禅(vipassanā毗婆舍那)就是连续不断地观察五蕴或六处、或六界的生灭、苦、无我的现象，它将渐次地引导由粗略到细腻的观察，所谓的「细腻」是观察到究竟「色法」、究竟「名法」。修习观禅只需要近行定(upacāra samādhi)或刹那定，观察、辨别究竟「色法」、「名法」的「自相」(sabhāva-lakkhaṇa自性相，各自的特质)，以及十二支「缘起」的因缘流转(一因缘之生是另一因缘生的条件)与还灭(一因缘之灭是另一因缘灭的条件)；也观察、辨别它们的「共相」(sāmañña-lakkhaṇa，指无常、苦、无我)。透过修习毗婆舍那而不被爱染、邪见牵引，最后体证究竟色法、名法灭尽而体证「涅槃」。

10.为什么有人修习止禅(samatha)、观禅(vipassanā)多年而不得证得道果？(课外题，仅供参考)

答：无因人(ahetuka)及二因人(dvihetuka)，及犯五逆罪者，无法证得禅那或道果。

三因人(tihetuka)修习止禅(samatha)、观禅(vipassanā)，要解脱当具足解脱的因缘条件，依经说是要具足「成熟解脱智」。(见A.9.3./IV,357；Ud.4:1./p.36；《中阿含56经》)

《中部注》(MA.147./V,98.)说有十五项成熟解脱智内容──五解脱智成熟想(pañca vimuttiparipācanīyā saññā)—无常想aniccasaññā, 无常苦想anicce dukkhasaññā, 苦无我想dukkhe anattasaññā, 断想pahānasaññā, 离贪想virāgasaññā.(又见D.33/III,243)；

尚有五法──亲近善友、持戒(守护波罗提木叉之律仪)、论法(少欲.知足、远离、不杂、精勤、戒.定.慧.解脱.解脱智见论)、精勤(发勤断诸不善法，具足诸善法而住)、智慧(通达生灭)(又见A.9.3/IV, p.357；Ud.4:1/p.36；《中阿含56经》)；

尚有五根(pañcindriyāni)──信根saddhindriyaṁ, 精进(勇猛)vīriyindriyaṁ, 念根satindriyaṁ, 定根samādhindriyaṁ, 慧根paññindriyaṁ。

以生活上来说，要具足身口意三妙行，持守戒律，放弃种种执取，放弃眷恋种种事物。为了对食、衣、住、药的不执取。有人实践十三头陀行，但是有的实践者却生起了另一种自命清高的执取(我慢)。清理执取及执取的根源，常常修习无常观，才须可能证得道果。

1. 如何克服一般的恐惧？ 

答：恐惧是欲界的嗔，证阿那含果(三果)才会灭绝，但持戒，或修止观可以暂时停止恐惧。

     持戒︰《增支部》A.10.92./V,182~4.︰持戒，停止杀、盗、淫、妄、酒，就可以止息五种恐惧，成就四预流支。杀生等，于现法生怖畏、怨雠，也于来世生怖畏、怨雠，于心中受苦、忧。若能远离杀生，则于现法不生怖畏、怨雠，也于来世不生怖畏、怨雠，于心中不受苦、忧。(cf.A.9.27./IV,405.，《杂阿含968经》(T2.248.1)，《别译杂阿含202经》(T2.448.2))

修止：把心固定在一个所缘，乃至入定可以暂时停止恐惧。

　实例：《森林回忆录》提到有位行脚僧阿姜草(Chaup)在森林中，遇到老虎，因害怕的关系，阿姜草站著，发展强大的念力(「害怕」是引起精勤的近因之一，《增支部》A.4.113./II,115：「怖畏者，从根源的努力。」(Saṁviggo yoniso padahati)。)，而入了定。等出定之后，老虎已经走了。专家认为，面对猛兽，最好停下来，不要动，猛兽对静止不动的物体，不作反应，或不攻击。若面对猛兽，拔腿就跑则无疑送死。(《香光庄严》第六十五期，pp.15~16, 30)在经行时，遇上猛兽，最好不要再移动身体。修慈心观，或修止观。

修观：吸气，观察在身体产生恐惧的现象(发抖、发冷)；呼气，观察在身体产生恐惧的现象。正念强有力时，一观察立即消灭。就像日中炽热铁器上滴水，立即蒸发(S.35.203./IV,190.)。有时需要几小时，乃至几天、几个月来消除恐惧。观察恐惧没有马上见效，是因为有恐惧的燃料，燃烧、慢慢燃烧须要有时间来让它消耗。

实例：《怖骇经》M.4./I,21.：「于是，我于其后特定之夜，即半月之十四日、十五日及八日之夜，于旷野的庙、森林的庙、树下的庙等住宿，甚为恐怖，身毛竖立。我住该处，有野兽靠近、有孔雀打落树枝或风吹动落叶声。那时，我这样想：「畏怖从此方向来。」那时，我又这样想：「为什么我在此一再等待畏怖？不如我如实向我而来之可怕的畏怖，我就这样如实排除畏怖。」于是，在我经行时，畏怖来临，那时，我只要正在经行，不停止、不坐、不卧，而如实地于经行，排除畏怖(neva tāva tiṭṭhāmi na nisīdāmi na nipajjāmi, yāva caṅkamantova taṁ bhayabheravaṁ paṭivinemi.)。婆罗门！又我于站立时，畏怖来临；那时，我只要正在站立，不经行、不坐、又不卧，而如实地于站立，排除畏怖。又我于端坐时，畏怖来临；那时，我只要正在端坐，不卧、不站立、又不经行，而排除畏怖。又于我横卧时，畏怖来临；那时，我只要正在卧，不坐、不站立、又不经行，而排除畏怖。」)

 5. 为什么有人长时造不善，竟然还可以荣华富贵；而造善者，还有噩运？

答：台湾俗话说：「作恶作毒，骑马辘辂(lok-khok﹐车子行进声)；好心好行，无衫通穿(无衣可穿，形容很穷)。」事实是「善有善报，恶有恶报。」善绝对不会有恶报，恶绝对不会有善报。《杂阿含108经》舍利弗告诉将返回西印度的诸比丘：「诸尊！若受诸不善法因缘故，今得‘现法乐住’，不苦、不碍、不恼、不热，身坏命终生于善处者，世尊终不说言当断诸不善法，亦不教人于佛法中修诸梵行，得尽苦边。以受诸不善法因缘故，今现法苦住、障碍、热恼，身坏命终堕恶道中，是故世尊说言当断不善法，于佛法中修诸梵行，平等尽苦，究竟苦边。若受诸善法因缘，现法苦住、障碍、热恼，身坏命终堕恶道中者，世尊终不说受持善法，于佛法中修诸梵行，平等尽苦，究竟苦边。(以)受持善法，现法乐住，不苦、不碍、不恼、不热，身坏命终生于善处，是故世尊赞叹教人受诸善法，于佛法中修诸梵行，平等尽苦，究竟苦边。」(cf.S.22.2. )

现法乐住：diṭṭhi-dhamma-sukha-vihāra，有四种乐：

一、离欲乐 (nekkhammasukha)，即近行定之乐，它已经脱离五盖，紧接著将生起喜悦(pāmujja﹐pāmojja)、喜(pīti)、轻安(passaddhi)、快乐(sukha)及定力(samādhi)。

二、远离乐(pavivekasukha闲静乐)，断除诸欲、恶.不善法，证得初禅得离(五盖)生喜乐。

三、寂静乐(upasamasukha)，指第二禅以上至灭尽定(灭受想定)。

6. 无聊是什么心态？

答：无聊，是「莫明其妙的想攀缘，而眼前又没有适当的对象可攀缘」。无聊的当时，具有「欲」、「贪」心所，没有「喜」心所，也没有「掉举」(有「欲」就不出现「掉举」)。

7. 可以直观自他的过去、未来五蕴吗？

答：一般来说，一般人只能见到自己的现在五蕴。在禅定中或梦中，有时可以「见到」过去或未来五蕴。若修得「缘摄受智」(第二观智)者，则能观照自己的过去、未来五蕴；若修得「宿命通」者，则能自在地观照自他的过去、未来五蕴。

8. 如何心念不生起？

11. 转世投胎的「活佛」成立吗？

答：「蒙藏佛教对修行有成就，能够根据自己的意愿而转世的人称为‘朱毕古’（藏语）或‘呼毕勒罕’（蒙语）。这个字的意义就是‘转世者’或‘化身’。‘活佛’乃是汉族地区的人对他们习俗的称呼，…其实蒙藏佛教中并没有‘活佛’这个名词。又傣族佛教比丘被称为‘佛爷’，这也是汉人习俗上错叫出来的，他们自己并没有这种称呼。（赵朴初老居士《佛教常识答问》）

众生未得毕竟解脱，转世投胎是必然的，但是他们的生日(在母胎中算起)必须跟上一生的死亡日同一天。在实务上，必须验证他们的生日(在母胎中算起)扣除140天~280天，是上一生的死亡日。由出母胎的生日，加上280天（38周到40周的新生儿都称为足月儿），这中间若有早产(怀孕20~36周(140~252天)发生的分娩称为早产)，就须减少一些日子。这样比对，可以初步确定是否「转世者」。如果生日超过280天，是否会是「转世者」？这是可疑的，除非前世活佛先生到天或鬼神(不是中阴身)，但这种可能机率渺茫。据说，有禅修者曾转世为藏传坐床的活佛，但他并不是前世的活佛的转世。

进一步的判断，则须比对上一生的临死最后一次生起的心路所取的对象(或业)，是否跟这一生有分心所取的对象(或业)相同。能作这种判断的人，至少须具备第二观智(缘摄受智)的能力。

13. 阿罗汉为什么无梦？

答：「若是诸漏永灭无余，虽眠不名‘痴’」，阿罗汉远离颠倒「梦想」，毕竟无「梦」。阿罗汉的心是寂静的，在不主动去思惟时，亦无潜在推动的业习(anusaya随眠)，所以不会构筑一幕又一幕的梦境。《增支部》A.4.173./II,162.舍利弗说：「友！六触处无余离染，戏论灭、戏论寂止。」(Channaṁ, āvuso, phassāyatanānaṁ asesavirāganirodhā papañcanirodho papañcavūpasamo.)

14. 由耳根闻声，可否证得涅槃？

答：可以。其过程是：先由耳根闻声，取声音的生灭相，持续取声音的生灭相直到心能取生灭相。若观到心的生灭，再持续作观。若观智成熟的话，身体将会有消失的感觉，有时前五根没有作用。若观察到所缘的生灭相，继续观察它，更进一步，观智成熟的话，取所缘的灭相(灭时)，观察它的无常、苦、无我，再进展，将生起怖畏、过患、厌离、欲解脱…乃至体证涅槃。

《首楞严经》卷第六(观世音菩萨说)：「彼佛教我从闻思修入三摩地。初于闻中入流亡所。所入既寂，动静二相了然不生，如是渐增闻所闻尽，尽闻不住，觉、所觉空，空觉极圆，空、所空灭，生灭既灭，寂灭现前。忽然超越世、出世间。」（T19.128.3）这一段经文并没有明白地说明其过程。依巴利三藏所说，体证前后，觉(能)、所觉(所)是不空的，能觉之心(及心所)与所觉的对象(所缘)一直不销亡，除非入无想定及灭尽定。

19.说谎话属于什么心？

答：说谎(妄语)是覆藏真实；讲妄语之前那一刻，是覆藏真实而发言，覆藏属于「悭」心所，亦即是嗔。AA.8.67~8./IV,147.︰「非圣者之言︰(妄语是)非圣者所说，含嗔之说(sadosakathā)。」律藏说到，覆藏罪行是属于故妄语罪(sampajāna-musāvāda，故意说妄语)。《律藏》Vin.Mv.I,103.(CS:Mv.pg.141)：Yo pana bhikkhu…saramāno santiṁ āpattiṁ nāvikareyya, sampajānamusāvādassa hoti.(比丘忆念有罪而不发露，即是故妄语罪。)「不发露」(nāvikareyya)即是覆藏(罪)，「覆藏」(巴makkha；梵mrakṣa)即属于「悭」 (macchariya)心所，《清净道论》(Vism.107)说：「对于嗔行者则有忿、恨、覆(makkho)、恼、嫉、悭等法」。巴利阿毗达摩把「覆」纳入嗔组的悭心所。

别的部派的阿毗达摩立「覆」心所。《俱舍论》卷第二十一：「隐藏自罪，说名为覆。」(T29.109.2)《说一切有部品类足论》卷第三：「覆云何？谓隐藏自罪。」(T26.700.2)《大乘五蕴论》：「云何为覆？谓于自罪覆藏为性。」(T31.849.2)

《律藏》似乎没有直接解释「覆藏(罪)」是否属「嗔」，但《普端严》(Sp.Mv.V,972.;CS:Mv.pg.253)有一处说「忿怒即是忿」(Makkhanti kodhaṁ.)。此处巴利文「忿怒」(makkhaṁ)=覆藏(makkhaṁ)。

20. 障碍今生证得四道、四果的因缘如何？

答：欲界善趣众生，今生要证得四道、四果必须是三因众生，无因、二因众生，无缘证得。其他的障碍，如《一切善见律毗婆沙》说：佛告诸比丘：『我声闻弟子忆过去事，严好比丘第一，诸大德已说四波罗夷竟。』法师曰：「波罗夷有几？」答曰：「我今总说一切二十四波罗夷(catuvīsati pārājikāni)，汝自当知。」问曰：「何谓为二十四波罗夷？」答曰：「比丘有四，比丘尼不同波罗夷有四，十一人不得。」「何谓十一人不得？」答曰：「一者黄门(Paṇḍaka﹐男根毁损)，二者畜生，三者二根人(Ubhatobvañjanaka﹐两种性器官)，此三者受生无缘(Ahetukapaṭisandhika﹐无因结生者)故，名波罗夷。然此三人不障天道，于四道果中有障碍，是故名为波罗夷，此三人不听出家。四者贼住(Theyyasaṁvāsaka﹐假冒比丘)，五者破内外道(Titthiyapakkantaka以比丘身份归外道)，六者杀母，七者杀父，八者杀阿罗汉，九者坏比丘尼(Bhikkhuṇīdūsaka污比丘尼)，十者出佛身血，十一者破和合僧，此十一人，为所作故，不得道果故，名为波罗夷。贼住破内外道坏比丘尼，此三人不障天道，于四道果障碍。杀父、杀母、杀阿罗汉、出佛身血、破和合僧，此五重罪，此是五逆罪，天道道果悉障。」法师曰：「波罗夷有八合十九，复有比丘尼乐著白衣衣服，计成合为二十，此比丘尼亦不破戒，复有弱脊(mudupiṭṭhiko, 弯腰口含己根)，长根(长根者将己根著入肛门)，含他人根(=口交)，此是四，都合成二十四，最后四是随结。」法师曰：「何以含他人根名为婬法？此以欲意故名为婬，不得与比丘同住者，不得与布萨说戒自恣羯磨一切僧事，悉不得共。」(T24.759.1-2；cf.《普端严》Sp.Pārā.II,515.。另参考：《增支部》A.6.86./III,436.cf.；《相应部》S.25.1./III,225；《分别论》Vibh.341.)

21. 如何分辨念佛见佛，或见鬼见神？

答：念佛见佛，所见到的佛不是过去世所见到的，就是想像的，或鬼神所变化的，所见到的佛若是过去世所见到的，佛陀必然具有三十二相，比丘相(非一般见到的泥塑木雕或笔墨绘制有卷发、发髻的佛像)，且身光一寻(byāma；vyāma﹐成人身高的长度)，佛陀皆具有名色法，可以被观测及辨识。

若修过「色业处」(rūpa-kammaṭṭhāna﹐修持辨识各类究竟色法的禅法)、「名业处」(nāma-kammaṭṭhāna﹐修持辨识各类究竟色法的禅法)的行者，可由色法的种类，辨识观察佛陀具有色法，但是佛陀无法回答行者任何新提出的任何问题。但是佛陀(或其他众生)的六门心路，非一般修过「色业处」的人就能观察到。

若是见鬼见神，可以观察他是化生的欲界众生(79种色法)，或色界众生(39种色法)；可辨识他的「心所依处」(心色十法聚)，至于观察众生的心念，则需要修习神通。

若是想像出来的鬼神，并不具有名法、色法。有时见到的不是鬼神，而是过去曾在该空间活动的众生，或者是未来将在该空间活动的众生的名法、色法。

22. 圣者怕死吗？

答：死亡本身不是一种不可意境，但是临死出现的景象才须可意境不可意境之别。对凡夫和部分有学圣者，想到死亡或面临死亡，还会心怀恐惧不安。初果圣者未断嗔的原故，还怕死。四果圣者不怕死，已断嗔的原故。经中为有论及怕不怕死的问题，说到：有漏尽阿罗汉对地震、雷电霹雳、「一切诸法无常，灭尽无余。」不恐怖的说教。（《增支部》A.2.6/I,77.；《增壹阿含19.3~4经》T2.594）

23. 入灭尽定还有心吗？

答：灭尽定(nirodha-samāpatti)又称为「灭受想定」(nirodha-vedayita-samāpatti)，与无想定都是属于「无心定」。入灭尽定者，「想、受」皆止息，一切心心所法不生起，成为无心、无心所法(无苦.乐受)的状态，当然也不可能有所缘(对象)，只有阿那含及阿罗汉具有入非想非非想处者，才可以入灭尽定。世尊若要入灭尽定，同样是六识不生，没有「不起灭定现威仪(教)化(众)生」之理，没有「事灭定」之理。

异说之一：「谓譬喻者分别论师执：灭尽定细心不灭。彼说：无有有情而无色者，亦无有定而无心者，若定无心命根应断，便名为死非谓在定。」(《说一切有部发智大毗婆沙论》卷第一百五十二(T27.774.1)事实上，入灭尽定者，虽然无心业生色法还会继续生灭。

异说之二：《唯识论了义灯》卷第五：「问：住灭定者，世尊入灭定不？答：有三解：一云不入。若尔云何具诸功德？答成就灭定而不现起。二云入。若尔何故诃菩萨入？答：呵耽乐者，诸经亦有劝菩萨入。问：既入灭定六识不行。何能利生？答：由加行意愿力故，不起灭定现威仪化生，佛即任运不假加行。三云虽似入而实不入。传云：《思益经》说入理灭定识即不行，入事灭定识即犹起。言似入者，即事灭定。然传捡文三释之中第二释胜。」 (T43.746.1)

24. 世尊入灭之前曾先入「灭想定」，何以阿难尊者误以为世尊已入灭(parinibbuto)？

25. 听闻佛法为什么可以当下开悟、证果？

答：「敏锐的智者」(ugghaṭitaññū)是那类补伽罗在听法的同时产生法现观(Spk:S.6.1./I,202.：Yassa puggalassa saha udāhaṭavelāya dhammābhisamayo hoti)。听法时心寂静下来，寂静下来的心，取得声音，或呼吸的触，或感受当作目标，观到它(们)的生灭相，由此进入解脱。基本上这是「纯观乘者」(suddhavipassanāyāniko纯观行者)的进路。世尊说法中，经常说五蕴的各种行相，有人可以当座即「见法」，这是闻法而悟的，说是闻所成慧(sutamayā paññā)。还有思法而悟的，思惟蕴、处、界、缘起的各种行相，也可以悟的，说是思所成慧(cintāmayā paññā)。闻法、思法开悟，有的人在这一生并没有明显的修止修观，有别于修所成慧(bhāvanāmayā paññā)。闻法、思法开悟的路径，经中有透露一些讯息，《增支部》A.6.10./III,285.说：「圣弟子随念法时，那个心不缠缚于贪、不缠缚于嗔、不缠缚于痴；该心那时即依法而质直。」「质直心之圣弟子，随义(=经教)而得悦.乐，随法(=经教)而得悦，得法所引之(两种) 悦，悦者生(五种)喜，有喜意之身(=精神与身体)者轻安，身轻安者受乐，受乐者心得定(=安置于所缘)。」心得近行定或刹那定，就有机会取到色法、名法的生灭法，或观察到缘起及其生灭，继续观察生灭而得到观智，乃至解脱。

26. 要证得道、果是否要得禅那？

答：要证道(magga)、果(phala)之前，被鼓励修习「增上心学」(adhicitta-sikkha, AA.3.100./II,364.：adhicittaṁ samathavipassanācittameva.增上心︰止与观的心)。不一定修到安止速行心(appanājavana)或安止定(appanā jhāna)。证道之前(第一至第十三观智)的观智都没有安止速行心，当证得以涅槃为对象的「种姓智」(第十三观智)、「道智」(第十四观智)的观智，则已进入出世间禅那，在证得「果智」(第十五观智)的心路(cittavīthi)，则是出世间安止心(appanācitta)。

    以未修禅那者而证得道、果来说，初禅的「道智」、「果智」各有36个心所，跟初禅安止心33个心所不同。

答：阿罗汉的「念」(sati)、「正念」(sammāsati)没有无明的成份，因此，他不会造作福行(善行)、非福行(恶行)、不动行(无色禅定的善业)。凡夫及有学圣者的「正念」，虽然正在生起的念头中，没有「痴心所」(无明)，但是「正念」的善速行心，还会成为未来结生或成为善的果报。因此，可以说凡夫及有学圣者的「正念」，含有无明的潜力。

28. 心识与心所依处色依靠的关系如何？

答：出生时，心识(citta﹐manas﹐viññāṇa)与心所依处色(hadayavatthu﹐hadayarūpa) 相互依赖而同时存在，即十二因缘的「(结生)识缘名色」(Viññāṇapaccayā nāmarūpaṃ)。结生心灭了之后，另一个心识(第一个有分)出生，它依靠结生心产生的(住时的)心所依处色，如此，每个心识依赖前一心产生的所依处色。若是五识之一，则依赖「过去有分心」产生的净色。

以人类来说明，人的心所依处色活动于心脏，当心识产生时，心所依处色。若是梵天界的众生(初禅天至第四禅天)，全身由「心所依处色」及「命根九法聚」遍满，梵天身没有像欲界众生构成身体成份的「身净色」。无色天界的众生，因为没有色法，心识不依靠色法而存在。无想天只有「命根九法聚」，没有心识，也没有「心所依处色」。

当心识不存在，是1.死亡时(已往生)，2.入无想定时，3.入灭尽定时，「心所依处色」状况如何？死亡时，心识与「心所依处色」(业生色)同时灭尽；入无想定及入灭尽定时，因为业报未尽，「业生色」还在，因此，「心所依处色」还存在。

29. 发心出家具有什么心？

答：▓发善心为得涅槃或修善法出家，就具有智相应的善心；若是胡涂出家，则是智不相应。

▓发不善心(为得名闻利养)出家就具有不善心。

实例：《增壹阿含49.9经》佛告提婆达兜：「汝宜在家分檀惠施。夫为沙门，实为不易。」是时，提婆达兜复再三白佛言：「唯然，世尊！听在末行。」佛复告曰：「汝宜在家，不宜出家修沙门行。」尔时，提婆达兜便生此斯念：「此沙门怀嫉妬心，我今宜自剃头，善修梵行。何用是沙门为？」是时，提婆达兜即自退归，自剃须发，著袈裟，自称言：「我是释种子。」(T2.802.2)

▓证得阿罗汉果才出家，则具有唯作心。

实例：《律藏》〈大品〉(Vin.Mv.p.17.)举耶舍(Yasa)居士证得阿罗汉，世尊才跟他授比丘戒。

30. 巴利阿毗达摩说「色聚」--八不分离色为地、水、火、风、色、香、味、食素，《俱舍论》说：色聚含有：地、水、火、风、色、香、味、触，如何知何者为正确？

答：色聚(rūpa-kalāpa)中的「食素」(ojā﹐āhāra rūpa；nutrition段食)是具有「特相、作用、现起、近因」可被观察与检视，但是必须修持四界分别观(catudhātuvavatthāna)成就，然后再修「色业处」(rūpakammaṭṭhāna)，才能观察「色聚」。色聚有四种，即由业、心、时节、食（kamma﹐citta﹐utu﹐āhāra）产生的，在任何一粒色聚中，都可以发现到「食素」。

「食生食素」(食生色聚中食素)，除了支助其他的「食生食素」之外，这食素若支助业生色聚当中的食素，又可以产生四或五代的业生食素八法聚；若支助心生色聚当中的食素，又可以产生二或三代的心生食素八法聚；若支助时节生色聚，可以产生十至十二代的时节生食素八法聚。因此，可以确定「食素」的存在。

《俱舍论》说的色聚八法中，包括「触」，不包括「食素」。「触」属于包括在「地、火、风」，在巴利阿毗达摩中，谈「色聚」，「触」不被独立出来，纯八法聚之外，九法聚、十法聚、十一法聚、十二法聚、十三法聚，都不包括「触」的法。

31. 为什么「界限界」( ākāsadhātu(虚)空界)属于色法？

答：「名法」(或名聚)有倾向之意(namatīti nāmaṁ)，当作能缘；「虚空界」没有倾向之意，不能当能缘，亦即非「名法」。「虚空界」也跟涅槃法不相干。在色法中，「虚空」属于十种「不完成色」之一。「不完成色」非四种色法的因造成的，它虽然不是实质的色法，也不具有「共相」(无常、苦、无我)的特性，但是它具有「自相」，即能辨别出它的特相、作用、现起(果)、近因(足处)，可以确定它的存在。

34. 试论：「生、灭」、「生、住、灭」，或「生、住、异、灭」哪一种说法正确？

答：经中常说「生灭」(udayabbaya)，而《增支部》（A.3.47./I,152）说：「缘生法有三相，即：生、灭、及住立的变易。」「住立的变易」（ṭhitassa aññathatta）即是指住时。巴利三藏的阿毗达摩则说，生(jāti；genesis)、住(ṭhiti；stasis)、灭(bhaṅga；decease)。

以色法来说──

在一粒色聚里的「火界」(或时节utu)或「食素」(ojā)有能力资助业、心、时节或食所生的色聚制造新的色聚，只在「住时」(ṭhitikāla；或住刹那ṭhitikkhaṇa)，在「火界」的资助，产生下一代的时节生食素八法聚（utuja ojā aṭṭhamaka rūpakalāpa）；在「食素」的资助，食生食素八法聚（āhāraja ojā aṭṭhamaka kalāpa）。在「生时」、「灭时」，则不制造心的色聚。

  以名法来说──

「心生色」──产生于结生后的第一个有分心的「生时」(第一刹那分)时，「住时」、「灭时」不生任何「心生色」。直到死心灭去后，才停止产生；

「业生色」──从结生刹那(paṭisandhikkhaṇa)开始，在每一刹那分(生时、住时、灭时)生起，直到死心生起前的第十七个心识刹那的「住时」，才停止产生；

「时节生色」──从结生识「住时」(第二刹那分)时生起，之后，每一刹那分「住时」都会产生时节生色，直到死心的「住时」，才停止产生。

「食生色」──从结生识「住时」(第二刹那分)时生起，之后，每一刹那分「住时」都会产生食生色，直到死心的「住时」，才停止产生。

不论名法或色法，在刹那生灭中，只能观察到「生时」、「住时」、「灭时」。

「生灭」(udayabbaya(ud-aya+vy-aya))，在经中用来表达「无常」(anicca)。只说「生、灭」二刹那，只是简约说，没有意味否定「住刹那」。不过有人否定「住刹那」，《入阿毗达摩论新疏》(Abhidhammāvatāra-abhinavaṭīkā CS:p.2.183)引用阿难陀长老(《阿毗达摩初疏钞》Mūlaṭikā的作者)说：「心的‘住刹那’不存在。」(Ānandācariyo pana “cittassa ṭhitikkhaṇameva natthi.”)。他只承认「生刹那」(uppādakkhaṇa)及「灭刹那」(bhaṅgakkhaṇa)。

36. 为什么「涅槃」不说是「断灭」？

答：「涅槃」是透过修道而证得，「断灭」是一种「一无所有」(na hoti)的见解。经中有一具体的案例，焰摩迦比丘认定身坏命终是断灭无有。《相应部》(S.22.84./III,109.；CS:p.2.90)说：「当时，有比丘名为焰摩迦，起如是恶见：照我了解的世尊教导的法，漏尽比丘身坏、灭绝、消失，死后无有(断灭) (yathā khīṇāsavo bhikkhu kāyassa bhedā ucchijjati vinassati, na hoti paraṁ maraṇā”ti.)。」

「断灭」(na hoti，=ucchedadiṭṭhi断灭见)表达与「常见」(sassatavāda)的见解。《相应部》(S.22.85./III,112.) 具寿舍利弗对具寿焰摩迦说：「朋友，焰摩迦！既然在真实的现世中，于此处(五蕴)，真实、常住(不变)的如来是不可得的，你怎么可以作这样的记说：「照我了解的世尊教导的法：漏尽比丘身坏、灭绝、消失，死后无有(断灭)？」

「断灭」：经中也称作「无有爱」、「灭爱」。什么是「无有爱」？《长部注》(DA.15./I,500.；CS:p.2.90)：「无有爱--伴随断灭的(粉碎的)见解的染著。」(Vibhavataṇhāti ucchedadiṭṭhisahagato rāgo.)。《长部注》(DA.33./III,988.；CS:p.3.170)：「无有爱--伴随断灭的见解的染著、有染、心的有染。」( Ucchedadiṭṭhisahagato rāgo sārāgo cittassa sārāgo, ayaṁ vuccati vibhavataṇhā.)「灭爱--伴随断灭的见解的染著。」(Ucchedadiṭṭhisahagato rāgo nirodhataṇhā.)

世尊也曾利用「断灭」之词，来说正确的法。《增支部》A.8.11./IV,174.：「婆罗门！我说贪嗔痴之断灭(ucchedaṁ vadāmi rāgassa dosassa mohassa)，说种种恶不善法之断灭(anekavihitānaṁ pāpakānaṁ akusalānaṁ dhammānaṁ ucchedaṁ vadāmi)。婆罗门！有此事由，依此事由之故，正说者谓我：沙门瞿昙乃断灭论者(‘ucchedavādo samaṇo Gotamo’ti)。」

39. 试论：「一切法无生、无灭、无所造作」。

答：涅槃是「无为法」(非因缘所造作而成的法)，它是无名法、无色法，也没有名色法的生灭，所以可以说「无生、无灭、无所造作」，但是「有为法」(因缘所造作而成的法)不可说「无生、无灭、无所造作」，大乘性空系说，「一切法无生」，若只限定在「无为法」则属正确，若涵盖「有为法」则属于逻辑辨证或玄谈，「但有言说，问已不如，增益生疑，以非境界故」。在巴利三藏的传承中，世尊没有说过：「一切法无生无灭，本来寂静自性涅槃。」

以觉者(阿罗汉)的「心」来说，平常生起的世间的心是生生灭灭。以涅槃为对象时(入果定phala-samāpatti)，当时每一个心识刹那(安止速行心，能观之心)是生灭的，但是涅槃的「境」是无生(即无任何名法、色法的生住灭)。

40. 什么是施者受者在布施前、布施时、布施后的正确态度？

41. 脱离轮回，是否由十二缘起支中的某支脱离？

答：若是观察缘起法，是观察「一组因缘生，一组因缘灭」，任何一组，即「过去有五因(无明、行、爱、取、有)，产生现在有五个果(识、名色、六处、触、受)」；或「现在有五因(无明、行、爱、取、有)，产生未来有五果(识、名色、六处、触、受)」，观察其因其果及其生灭，可脱离轮回，达到究竟涅槃。由观名法、色法的究竟法的无常、苦、无我，同样可以脱离轮回。

有人说，正念于‘触’或‘受’，「就不会引生爱、取、有、生」，这是不正确的。具正念时，就没有「爱」、「取」二支，但是还是有欲界、色界、无色界善心的「(业)有」，一样会引生「生」。

44. 死亡最后一口气是吸气还是呼气？

答：《中部》(M.62./I,425f.)世尊说：「罗睺罗！如是修习多作安般念之时，你必知‘最后的’出息入息之灭，不是不知的。」( “evaṁ bhāvitāya kho, Rāhula, ānāpānassatiyā evaṁ bahulīkatāya yepi te carimakā assāsapassāsā, tepi viditāva nirujjhanti, no aviditā”ti)。

48.为什么只有身乐受、身苦受，没有身不乐不苦受(身舍受)？

答：《分别论》#180.︰Tattha katamā upekkhādhātu?  Yaṁ 1cetasikaṁ neva sātaṁ nāsātaṁ 2cetosamphassajaṁ adukkhamasukhaṁ vedayitaṁ 3cetosamphassajā adukkhamasukhā vedanā– ayaṁ vuccati “upekkhādhātu”. (此中，什么是‘舍界’？凡是1心既非愉快也非不愉快、2感受心触产生不苦不乐、4心触产生不苦不乐受，这称为舍界。)舍界只论及心，没有论及身。

因为身体只承受善恶之报。善报则身乐识，恶报则身苦识，身体没有不苦不乐报。

造身口意不清净的恶业(黑业)，导致全然身苦受及不如意境的果报(kammaṁ kaṇhaṁ kaṇhavipākaṁ黑业黑报)；造身口意清净的善业(白业)，导致全然身乐受及如意境的果报(kammaṁ sukkaṁ sukkavipākaṁ白业白报)；称为「黑白业黑白报」(既非全善也非全恶的业)(kammaṁ kaṇhasukkaṁ kaṇhasukkavipākaṁ)，是属于身口意夹杂清净及不清净的业的果报，仔细分析的话，它的受报是夹杂的，有时是黑业黑报，有时白业白报。因此，没有身体不苦不乐受(舍受) 的果报，也没有「既非如意境也非不如意境的果报」。(详见《增支部》A.4.231-2/II,230-2.)

身体感觉不苦不乐受(舍受)(cf. S.48.37./V,210.)，其实是微弱苦受或乐受，其中，善业的果报是乐受，恶业的果报是苦受。

49. 喜（pīti）与乐（sukha）的差别如何？ 

答：「喜」是欢喜，属于行蕴；「乐」是快乐，属于是受蕴。

虽然「喜」与「乐」两种往往是不相离的，对于乐的所缘而获得满足为「喜」，去享受获得了的滋味为「乐」。有「喜」必有「乐」；有「乐」不必有「喜」。犹如在沙漠中困疲了的人，见闻于林水之时为「喜」，受用于水之时为「乐」。禅那的「喜」和禅那的「乐」，名为此禅那的「喜乐」。此禅的「离生喜乐」，或说「离(五盖)生喜乐」。(参考：《清净道论》Vism.145)

50.「悭」与「贪」能否同时存在？

答：「悭」与「贪」是不能同时存在。出现「悭」（macchariya﹐吝啬，不布施）心所时，不会同时出现「贪」（lobha）心所。

51.植物人还有心吗？

答：只要有呼吸，就有心。因为有心，心会因生理的需要，来命令「吸…」，或命令「呼…」。心是因，身体、肺、鼻等是缘，「吸」或「呼」是果，它是因、缘、果的进行方式。甚至于在睡觉中，它也是这样的进行方式，在睡觉中，心虽然一直持续命令「吸」或「呼」，心的命令是很微细的，不会把人吵醒。

植物人(brain dead, in a vegetative state)不管自己呼吸，或靠机器来维持生命，他必然有「心」。经典说「寿、暖、识」(āyu usmā ca viññāṇaṁ)三者若同时离身，则叫做死亡；没有「心」的话，四因所生及维持的身体就会败坏，届时死者继续靠机器，也无法维持假的活著；若是保温的话，则身体败坏、发臭将会加速。身体败坏、发臭，表示已无心识。而植物人的身体不败坏、不发臭，表示有心识。

答：「妄语」属于覆藏真实，覆藏属于「悭」，即嗔根之一。
