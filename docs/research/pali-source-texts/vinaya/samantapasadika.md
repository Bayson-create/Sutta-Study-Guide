# 《善见律毗婆沙》全书重组详解

> 版本：T24n1462，萧齐外国三藏僧伽跋陀罗译（CBETA 2023.Q4）。
>
> 阅读方法：本书虽题作「律毗婆沙」，并非只逐条注释戒相。它先交代佛灭后三次结集、律藏传承与南传师子国（今斯里兰卡）佛教的建立，再以舍利弗、优波离等人的问答，展开广大的律学释义。以下保留原书六品，却将卷次中反复出现的同一议题合并，并依「为何要有律—律如何建立—如何判罪—如何修复僧团」的脉络重排。

## 全书主旨与总线索

本书的核心判断极鲜明：**毗尼不是外在的束缚，而是正法在世间的寿命、僧团得以自净并引向定慧解脱的骨架。** 开篇即发愿「至演毗尼义，令正法久住，利益饶众生」，后文反复将这个愿望落实为传承、结集、制戒、忏悔与羯磨。

全书可收束成一条因果链：

> 戒止恶 → 不悔 → 欢喜 → 安乐 → 三昧 → 慧眼 → 厌离 → 离欲 → 解脱 → 解脱知见 → 涅槃。

原文说得极有力量：「佛说戒律，为欲止恶因，止恶故生不悔心……因度脱智，次第得入涅槃。」因此，学律不是为了挑错或堆砌禁令；它是把身、口、意从粗重失序中调伏出来，使解脱有可走的道路。

## 一、序品第一：佛灭后，何以必须先结集毗尼？

### 1. 结集的导火线：一念放逸足以毁坏共同体

佛在拘尸那入无余涅槃七日后，摩诃迦叶率众前往吊唁。大众悲恸时，老比丘须跋陀罗摩诃罗却说：

> 「大沙门在时，是净是不净、是应作是不应作。今适我等意，欲作而作，不作而止。」

这一句不是个人的牢骚，而是僧团若失去共同准则后的完整预告：把戒从「佛法的师」降格成「我喜不喜欢」。迦叶因此不只哀悼佛陀，而是立刻想到「恶法未兴，宜集法藏；若正法住世，利益众生」，决定集出法藏、毗尼藏。其根据是佛的遗教：「我涅槃后，所说法戒即汝大师。」

### 2. 籌备结集：正法不是抽象理念，须有制度与人

迦叶选五百爱尽阿罗汉。阿难因仍在有学位，起初被排除，以免招致「偏爱近侍」的讥嫌；但众僧指出阿难亲闻经法、记忆无缺且无偏党，若不用他便无人能出法。这呈现结集的两个尺度：**证量确保可信，记忆确保传承。**

众人选王舍城安居、修缮十八座破败寺院，又请阿阇世王建讲堂。这些细节说明护法不离日常事务：寺舍荒废，外道便可讥称佛灭后弟子弃置一切；先修房舍，正是先护僧团的可见形象。

阿难在结集前夜精进过度而未果，转念取其中道；正当「脚已离地、头未至枕」的非行非住非坐非卧之间证阿罗汉。这段不只传奇，更以身示范：修行不取躁进，适度调心反能突破。

### 3. 第一次结集的次第：先律、后经

众僧明确决定「毗尼藏者是佛法寿，毗尼藏住佛法亦住」，所以先问优波离。迦叶每一条都追问：何处说、因谁起、犯何罪、如何结戒、是否有随结；优波离逐一回答。比丘、比丘尼的波罗提木叉，连同犍度（杂事）与波利婆罗（附随的羯磨、摈治规则），于是被确立。

律藏既出，才由阿难结集法藏，从《梵网经》《沙门果经》的说处、因缘开始，整理为五阿含。这个顺序并非贬低经教：它指出若共同生活先瓦解，经义再深也无处安住。

### 4. 三藏、五阿含与「一味」：不同分类只为一件事

- **二藏**：法藏、毗尼藏。
- **三藏**：毗尼、修多罗、阿毗昙。
- **五阿含**：长、中、相应、增一、屈陀迦；后者收摄四阿含外的其余佛法。

虽有种种分类，佛四十五年所说皆以解脱为「一味」。本书用建筑、编织与泉水说明三藏：毗尼调伏身口；修多罗如线贯花，令法相不散；阿毗昙以细密分别开发智慧。三者各有作用而不可偏废：依律行可入定、由定发通慧；学阿毗昙能生实智、具四辩；随经教而行，能知出家修道的方向。

它也警告两种偏差：不智而妄解佛教，会诽谤、造恶、增长邪见；执阿毗昙过急、妄思不应思之事，反会令心狂乱。故结语是「比丘乐学者，当爱重此法」：重法不是偏执一门，而是知其位置。

## 二、跋阇子品第二：第二次结集——以十非法守住界线

佛灭一百年后，毗舍离跋阇子比丘中出现十非法：「盐净、二指净、聚落间净、住处净、随意净、久住净、生和合净、水净、不益缕尼师坛净、金银净。」表面看来有些只是生活方便，实则共同指向一件事：将戒的明确边界改作地方习惯与利益的弹性。

长老耶舍到毗舍离，见比丘在说戒日置满水钵，并向居士说「应与众僧钱」，便拒绝接受分配。跋阇子众试图以钱安抚、又企图令他认错；耶舍不受，最后由七百比丘集毗尼义，依律断十非法、消灭诤法。原文另说集会中有二万比丘，故不宜把七百概称为七百阿罗汉。

本品的教训不是「守旧」，而是：**当便利、供养与群众压力一同涌来，戒的判准须回到法与律，而非回到谁的声量较大。** 它也描出僧团解决争议的正面程序：不私下报复、不以金钱遮掩，而以合格的僧众、公认的律据和公开审议止诤。

## 三、阿育王品第三：第三次结集与佛法走向世界

### 1. 预见浊垢：大供养既能兴法，也能招来伪入道者

第二结集诸圣预见一百一十八年后阿育王大力供养，外道将为利养混入僧团，仍以旧法教人，佛法因而浊乱。他们请梵天帝须下生，成为目揵连子帝须。这位帝须先由和伽婆以「我往汝家七年，都无所得，昨始得家人语我更往余家，是故言得」的知足感化，再以四句心法难题折服其博学傲气：「若人心起而不灭，若人心灭而不起，若人心灭而灭，若人心起而起？」少年因此发心出家，速证初果，遍学三藏，终成破邪显正的关键人物。

这段特别突显护法者的养成，不靠权位而靠三件事：极深的知足、能击中执着的提问、完整的法与律教育。

### 2. 阿育王的转向：从权力与奇观，走向不放逸

阿育王早年杀兄弟而自立，最初承袭父王供养外道。外道在王前各取高下座位的画面，暴露其无法自量；相反，七岁沙弥泥瞿陀威仪安详，令王起信。泥瞿陀只说半偈：

> 「不懈怠者是涅槃，若懈怠者是生死。」

王要求说尽，沙弥却以受供分给和尚、阿阇梨、比丘僧的举动，让王看见僧团不是个人名望，而是师承、教授与僧伽。阿育王遂受三归五戒，广建寺塔、供养六万僧。

然而本书刻意校正王的自满。王问自己是否已「入佛法」，目揵连子帝须回答：再大的布施仍未足，能令亲生子女出家，才算真正投入法分。王遂允摩哂陀与僧伽蜜多出家。此处的重点不是鼓励每个父母都要送子出家，而是用最强烈的故事语言表示：**护法不只拿财物支持，而是肯把最珍爱的关係交给法。**

### 3. 第三次结集：先辨正见，才恢复共住

外道假比丘因失利养而混杂僧中，善比丘不肯与其共布萨，七年不能说戒。王本想以行政命令止争，大臣误解甚至杀害比丘，王悔惧。目揵连子帝须被迎回后，先以「有杀心不」为王辨明业的关键，再教王分辨「是律、是非律，是法、是非法，是佛说、是非佛说」。最后集合僧众辨别：外道各答常、断等偏执；合于佛法者答「佛分别说」。王遂遣还外道，六万比丘恢复布萨。

此后选一千通三藏、具三达智者结集，九月完成第三集。这段的程序伦理很重要：王可护持安全与资源，**却不可用武力替代僧团对法义的判断**；清净不是排除异己，而是检验是否依佛的缘起分别、是否受持共同律制。

### 4. 弘法地图：从中央王朝到边地

第三结集后，目揵连子帝须派遣弟子到罽宾、揵陀罗、摩醯娑、婆那婆私、阿波兰多迦、摩诃勒咤、臾那、雪山、金地及师子国。每一地都以最相应的法门化导：

- 末闡提伏阿罗婆樓龙王的嗔害，令其受三归五戒、不再毁坏禾稻；
- 摩诃提婆说《天使经》，使四万人得道；
- 勒弃多说《无始经》，六万得天眼、七千出家；
- 昙无德说《火聚譬经》，令三万人得道；
- 须那迦欝多罗在金地先以神力止夜叉害嬰，再说《梵网经》，建立四众。

叙事虽充满神异，内在结构一贯：先解除地方最深的恐惧、暴力或灾害，再以契机经法建立三归、五戒与出家众。弘传不是把同一套话硬塞到各处，而是以不害、安乐与解脱回应当地真正的苦。

### 5. 师子国的建立：法要「根株着地」

摩哂陀率众至师子国，先试天爱帝须王的辨析力，后说法令王与四万人受三归。王提供眉伽园，摩哂陀说《饿鬼本生》《宮殿本经》《天使经》等，王后阿㝹罗与五百夫人、众多人民相继得道。接着迎佛舍利建塔、迎僧伽蜜多与菩提树，并授比丘尼戒，令四众具足。

最关键的定义在此：王问佛法是否已在本国「根株着」，摩哂陀答尚未；要等师子国父母所生的人出家，且出家后能「取法藏及毗尼藏」，在本地传诵、掌握并传授法藏与律藏，才算真正扎根。这是本书最成熟的弘法观：**佛教不是外来圣物、王室工程或神迹展览；必须转成在地人能自我教育、自我传戒、自我结集的活传统。**

菩提树自然分枝、舍利放光、地动等叙事，把这种「移植而生根」写成宇宙級的欢喜；但文本沒有停在奇迹，最后仍回到律藏的讲说与师师相承。

## 四、摩诃目揵连品：神通为何不可取代因果与常住法

毗兰若饥馑，目揵连想翻地取地肥供养僧众，甚至愿以神力托住城邑众生。佛却连说「止」。原因不是否定慈悲，而是看见后世的副作用：未来僧众若遇饑荒而无神通，世人会反推为「今僧持戒不具」，以颠倒见轻慢圣者，反堕恶趣。

本品也记目揵连想牽郁单越地近閻浮提，使人容易渡海取食。佛不許的底层原则相同：不能用一位圣者的非常能力，製造所有人都依賴的常態。**真正可普遍依循的救濟，是持戒、布施、正见与可持续的僧团秩序，不是神通捷徑。**

## 五、舍利弗品：从「正法何以久住」到完整律学（全书主体）

此品篇幅最长，原书随《律本》文句逐卷展开，故事与法条交错。以下依议题重排。

### A. 戒何时建立：不是预防性控制，而是随病授药

舍利弗问佛：何以有些佛法久住、有些不久住？佛答，过去诸佛的弟子根熟、心净时，只以「教授波罗提木叉」教导；当僧众混杂、漏法生起，才随犯结「威德波罗提木叉」。共同的教授偈中最核心的一段是：

> 「一切恶莫作，当具足善法，自净其志意，是即诸佛教。」

舍利弗请佛预先结戒，佛两次说「止！止！时未至矣。」并以医师为喻：未成病便割肉施药，病人只觉受苦；病起后对症下药，才知医者慈悲。故制戒不是先假設人人有罪，而是等「漏法」——煩恼、劫奪僧物、冒称沙门等——在共同体中实际出现，才以最必要的规则处理。

正法久住也不只是时间长短，而是法能否被「线」贯穿。原文说花不以线贯，風吹即散；僧众若出身、姓氏、习性各异而无共戒可承，亦易散乱。戒因此是多樣众人得以和合的线，不是同质化的枷鎖。

### B. 毗兰若飢年：供养、惭愧与佛的善巧

本品回到佛与五百比丘在毗兰若安居。婆罗门原已请供，却被魔所迷、三月全然忘记；僧众只得食马麦。安居后他羞愧请佛将三月供养合于一日，佛接受，并非贪受，而是怕拒绝使对方误解佛怨恨、非一切智或不能忍，反生重罪。佛受供后为其眷属广说法。

这一段把律的温度写得很细：犯失或失职者先要如实承认；有权拒绝者则须观察拒绝会不会使人堕入更深的恶见。规矩不取消悲悯，悲悯也不掩盖因果。

### C. 僧身与受戒：名相背后的真实条件

书中细辨「比丘」：乞士、着割截衣者、假名比丘、善来比丘等。衣钵、乞食、舍家并非表演苦行，而是切断佔有与身份炫耀的生活形式。受具足戒则有多种历史方式：善来、三归、受教授、答问、受八敬、遣使、白四羯磨等；最后以僧团羯磨成为常规。

它也反复强调授戒的资格与程序：僧数、界限、闻见、身根条件、和尚阿阇梨的臘数与教导能力皆不可草率。因为出家不是私人宣言，而是进入一个可教、可学、可承担责任的共同体。

### D. 判罪的总方法：先看心、事、境、方便与完成点

大量看似繁瑣的案例，实际上在建立精准的判准。可概括为：

1. **动机与认知**：是否有欲心、盗心、杀心？是否明知、故作、误认？有些性罪须心行俱具；有些制罪即使无心仍须注意。
2. **对境与关係**：对象是人、非人、畜生，或是女众、僧物、私物？是否有主、已舍、亲属、受托？对境不同，罪阶不同。
3. **行为阶段**：初方便、随方便、临结成与事成，罪可由突吉罗、偷兰遮递进至重罪。譬如盗物，触、动、离本处；教人偷盗，起教、受教、实际离处，各有不同后果。
4. **时间、空间、界与僧数**：明相、非时、聚落界、船渡、安居界、布萨界、法会人数，都是使行为可明确判定、可共同验证的条件。
5. **可否忏悔与如何修复**：波罗夷不可复本；僧残须依僧作法；偷兰遮、波逸提、提舍尼、突吉罗等依其法忏悔。目的不是貼标籤，而是止恶、发露、恢复清净关係。

### E. 四波罗夷：最重的边界不是恐吓，而是保护信任

本品对四重戒作极细的因缘释：

- **淫戒**：重点在欲心、相触、入处与是否受逼迫。以优钵罗华比丘尼遭侵害而「不乐故无罪」的故事，明确否定把受害者视作犯者。
- **盗戒**：以有主物、价值、盗心、奪取/搬移/越界/教他取等五法与多重方便，辨何时成重。其伦理核心是不可侵吞他人或僧团信托之物。
- **杀戒**：人命、非人、畜生及教唆、投毒、弃置的意图不同，罪相不同；以杀心为关键。
- **妄称圣法戒**：未证说证，侵害的是信众对修行与僧寶的信任；其严重不在一句话，而在以虛假换取敬信、利养或地位。

书中有大量极端边例，应把握其方法而非獵奇逐項背诵：戒学要防的是欲、贪、害与欺誑如何藉身口业落地成事。

### F. 僧残、二不定与日常戒：由「犯」走回「可共住」

十三僧残处理较重而仍可修复的行为，如故意出精、染心触女、作媒、谤、破僧、恶见不舍等。犯者须覆藏、别住、行摩那埵六夜，再由足数僧作出罪羯磨；「摩那埵」被解为折伏骄慢、下意承事众僧。这不是單纯处罚，而是以公开、持续而有见证的方式重建可信度。

二不定则提醒比丘不得与女人在足以生疑的屏处独坐；判处要听可信优婆夷的见闻，并依实情决定。其精神是既重防护、也重证据，不以臆测定罪。

接下来的尼萨耆、波逸提、提舍尼、众学等，覆盖衣物财物、饮食时节、住处、说话、威仪、与在家众往来等日常事项。看似细密，实则围绕几个常见失衡：利养积聚、对饮食的贪着、性别与权力界限、对居士家庭的侵扰、身口粗疏，以及以「修行人」身份索取便利。

「污他家」一段尤其尖銳：马师、满宿等人种花果、殷勤结交居士居士女以换取供养与眷属。律不許出家人把寺院经營成人情与利益网絡；但也允为三寶、病者、父母等以「净语」处理必要事务。原则不是断绝人情，而是不以宗教身份交换私利。

### G. 僧团程序：羯磨、诤事与迦絺那衣

本品不把僧团当成一群道德完人，反而详细設計人在衝突、犯错、分物、受戒时如何共同决定：

- **羯磨**须有合法界、足数僧、正确白文与程序；私自别众、白羯磨不成，皆会使结果失效或成罪。
- **四诤事与七灭诤法**：以现前毗尼、忆念、不了痴、罪处所、多人语、罪自言、如草覆地等方式，因应不同的事实与关係状態，目标是止诤而非取胜。
- **迦絺那衣**：安居后由合格僧众受持功德衣，分配优先照顾衣坏者与长老，不与悭贪者；其细节展现僧物不是谁势大谁得，而是依众、依法、依需要。

拘睒弥律师与经师因廁后洗器的小事互相轻慢，终成大诤的故事，警示「知罪相」若被拿来压人，而非幫人明白故不故作、犯不犯，律学本身也能成为我慢的工具。

### H. 以故事照见可度性：周罗般陀与佛的教法

周罗般陀四月诵不住一偈，被兄赶出寺。佛不以其钝根弃之，给他白叠，令反复念「取垢取垢」。布渐染垢，他观自身亦复无常败坏，终得解脱。故事与整部律的精神相应：不是以能力、出身或一时失败定人，而是找到其心可转的入口；戒的细行，若能如实观照，也能成为见法之门。

## 六、大德舍利弗问优波离律污出品：把庞大律藏压縮成「可检索的索引」

末品以三十二组偈颂问答，像律藏的速记总表。舍利弗问「几罪以身得？几罪以口得？覆藏得几罪？相触复有几？」优波离以数目答，再逐条解释。这不是另立新义，而是把前面广说过的戒相，按「触发条件—罪聚—忏悔程序」重新编码，方便律师记忆、查核。

最值得掌握的几组总纲如下：

- **身、口、覆藏、相触**：身得六类、口得六类；覆藏重罪会依「尼自覆、比丘覆他、比丘自覆」而有不同罪；相触须区分比丘尼、比丘、衣与身、对象等。
- **时空与渐次成罪**：入聚落、渡江、昼夜屏处、明相出等，往往从初动到越界、双足入境，罪相逐步加重。这印证前品「完成点」的判罪法。
- **可忏与不可忏**：五类罪可依法忏悔；僧残须羯磨处理；波罗夷不可复本。此处的不可忏不是否定悔改的道德可能，而是指不能恢复比丘身分与原有僧团资格。
- **衣食与受施**：七日药、美食乞求、非时食、受染心者施食等，皆用来保护出家者不以需求为名滑向贪求或暧昧依附。
- **五众与灭诤**：比丘、比丘尼、式叉摩尼、沙弥、沙弥尼皆有相应的发露、诤事与清净程序；法不是只管「犯者」，而是让整个群体有回到和合的路。
- **八、十、十二等记忆群**：八敬法、八语受戒、八德教诫尼、十种不应礼与叉手、十二非法羯磨等，把散见规条聚成可背诵的模组。

末后一句「随大德所问，我亦随意答。问问中即答，无有一狐疑」，为全书收束：律师的理想不是以知识压倒人，而是面对具体情境，能无疑地判明事实、罪相、修复方法。

## 结语：本书交给读者的，不是一套苛细规条

《善见律毗婆沙》从迦叶闻见放逸之语起筆，至舍利弗、优波离的问答索引收束，始终在回答同一问题：佛已不在，众人如何不让法散掉？它的答案有四层：

1. **以戒为共同的师**：不让个人好恶、地方习俗或利养取代法则。
2. **以传承与教育为根**：法要由能持、能说、能教的人代代相付，并在本地真正扎根。
3. **以精确判断取代含混道德化**：动机、对境、行为、界限、程序与后果都要如实辨明。
4. **以发露、羯磨与慈悲完成修复**：律不是只问「谁该罚」，而是使犯者、僧团与信众不被煩恼拖散，重新回到清净、和合与解脱的方向。

最浓縮的提醒，仍是开篇和全书反复证明的那句：

> 「毗尼藏者是佛法寿，毗尼藏住佛法亦住。」
