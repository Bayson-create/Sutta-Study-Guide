815-6. “在所有这些业处中都能生起禅吗？”“是的，一切业处皆能生起近行禅，但某些业处不能生起安止禅。因此，有些仅生起近行禅，有些亦能生起安止禅。”此当如何理解？故说“于此等”等。对于“仅引生近行”，如同在“apekkho”等词中，此处的“eva”应理解为限定义。其中，除去入出息念与身至念，其余的佛随念等八种随念，以及想与差别，此十种业处，因其所缘种类繁多、甚深，且为自性法，若无特殊的修习，则被称为仅引生近行者。
815-6. Does jhāna arise in all these meditation subjects? Yes, access jhāna arises in all of them, but absorption jhāna does not arise in some. Therefore, some produce only access concentration, while others produce absorption as well. But how is this to be understood? It is said, “In these…” and so on. Those that bring only access are 'access-bringing.' Just as in cases like 'the hopeful one,' here too, the exclusive sense should be understood.
